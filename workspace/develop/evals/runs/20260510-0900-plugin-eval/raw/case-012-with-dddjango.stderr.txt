def create_coupon_issuance(request, payload: CouponIssuanceCreateRequest):

**Status Codes**

- `201 Created`: 새 쿠폰 발급 성공
- `400 Bad Request`: 필수 header 누락, 잘못된 content type 등 요청 형식 문제
- `401 Unauthorized`: 인증 없음
- `403 Forbidden`: 발급 권한 없음
- `404 Not Found`: 쿠폰 정책이 없거나 클라이언트에 노출하면 안 되는 정책
- `409 Conflict`: 이미 발급됨, 재고 소진, 같은 `Idempotency-Key`로 다른 payload 재시도
- `422 Unprocessable Content`: 스키마는 맞지만 claim code 불일치 등 의미 검증 실패
- `429 Too Many Requests`: 발급 요청 rate limit 초과
- `503 Service Unavailable`: 외부 의존성 장애가 있고 재시도 가능할 때, `Retry-After` 포함

**Problem Details**

```json

  "title": "Coupon already issued",

```

Validation 오류는 `errors` 확장 필드에 field-level detail을 둔다. HTTP status와 body의 `status` 값은 항상 일치시킨다.
