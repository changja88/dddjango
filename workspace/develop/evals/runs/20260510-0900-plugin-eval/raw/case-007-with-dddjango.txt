현재 작업공간을 확인했지만 실제 Django `Order` 모델 파일은 없고, 관련 요청 문구만 문서에 있습니다. 그래서 파일 수정은 하지 않았습니다.

필요한 작업만 정리하면 이 정도입니다.

1. `Order` 모델에서 `memo` 필드를 `note`로 이름만 변경
2. 마이그레이션은 데이터 보존을 위해 `RemoveField`/`AddField`가 아니라 `RenameField` 사용

```python
migrations.RenameField(
    model_name="order",
    old_name="memo",
    new_name="note",
)
```

3. `memo` 직접 참조만 `note`로 변경
   - admin, form, schema/serializer, view, template, factory, fixture, test
4. 검증은 작게
   - `python manage.py makemigrations --check --dry-run`
   - `python manage.py migrate --plan`
   - 관련 앱 테스트만 실행

과하게 할 필요 없는 것: DDD 재설계, service/usecase 분리, repository/UoW, subagent/workflow 계획, DB rollout 전략. 단순 rename이면 마이그레이션과 참조 수정이면 충분합니다.

실제로 실행한 명령:

```bash
pwd -P
git rev-parse --show-toplevel
rg --files
rg -n "\bmemo\b|class\s+Order\b|\bOrder\b" .
rg -n "\bmemo\b" . --glob '!workspace/develop/evals/**' --glob '!workspace/reference/**' --glob '!workspace/develop/**'
rg -n "class\s+Order\b" . --glob '!workspace/develop/evals/**' --glob '!workspace/reference/**' --glob '!workspace/develop/**'
```

실행하지 않은 체크: Django 테스트, `makemigrations`, `migrate --plan`, `sqlmigrate`는 실제 Django 앱이 이 작업공간에 보이지 않아 실행하지 않았습니다.

Serena: 이 세션에 Serena 도구가 없어 사용하지 않았고, `rg`로만 참조를 확인했습니다.
