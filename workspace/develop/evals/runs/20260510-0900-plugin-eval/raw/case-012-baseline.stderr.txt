Response schema:

```python
class CouponIssueResponse(Schema):
    coupon_id: int

```

Auth:

```python
@router.post(
    "/coupons/issue",
    response={201: CouponIssueResponse, 400: ProblemDetails, 401: ProblemDetails, 403: ProblemDetails, 409: ProblemDetails},
    auth=django_auth,
)
def issue_coupon(request, payload: CouponIssueRequest):
    ...
```

권한 정책:

- 인증 필수
- 관리자 또는 쿠폰 발급 권한 보유자만 발급 가능
- 일반 사용자가 자기 자신에게 발급하는 정책이 필요하면 별도 permission으로 분리

Status code:

- `201 Created`: 쿠폰 발급 성공
- `400 Bad Request`: 요청 값 오류, 만료된 정책, 발급 불가능한 정책
- `401 Unauthorized`: 미인증
- `403 Forbidden`: 권한 없음
- `404 Not Found`: 사용자 또는 쿠폰 정책 없음
- `409 Conflict`: 중복 발급, 재고 소진, idempotency 충돌
- `422 Unprocessable Entity`: schema validation 실패가 Ninja 기본 정책이면 사용

Problem Details:

```python
class ProblemDetails(Schema):
    type: str
    title: str
    status: int
    detail: str
    instance: str | None = None
    code: str | None = None
```

예시:

```json
{
  "type": "https://api.example.com/problems/coupon-already-issued",
  "title": "Coupon already issued",
  "status": 409,
  "detail": "The user already has this coupon.",
  "code": "COUPON_ALREADY_ISSUED"
}
```

- `operation_id`: `issueCoupon`

- 성공: 권한 있는 사용자가 유효한 정책으로 쿠폰 발급 시 `201`
