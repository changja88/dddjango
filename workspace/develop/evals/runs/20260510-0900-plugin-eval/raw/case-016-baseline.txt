요약: 현재 워크스페이스에는 `workspace/develop/source-crosswalks/`가 없고, 실제 runtime skill 위치인 `dddjango/skills/`도 없습니다. 그래서 crosswalk 기준으로 “source heading이 runtime skill에 어떻게 반영됐는지”는 per-heading 단위로 판정할 수 없습니다.

분류 결과:

| 구분 | 결과 |
|---|---|
| 포함 | 확인 불가. crosswalk와 runtime `SKILL.md`/`references`가 없음 |
| 병합 | 확인 불가 |
| 다른 skill 위임 | 확인 불가 |
| 생략 | 확인 불가 |
| source gap | 문서상 확인됨: `architecture-implementation-patterns`, `implementation-django-ninja`, `implementation-django-web`은 전용 source reference 부족으로 provisional 대상. `workflow-dddjango-subagents`는 `workspace/docs/workflow.md`를 source로 삼는다고 명시됨 |

근거:
`workspace/docs/reference-index.md`, `workspace/docs/skill-authoring.md`, `workspace/docs/plugin-structure.md`에는 위 source gap/provisional 상태가 명시되어 있습니다. 하지만 요청한 기준 파일인 `workspace/develop/source-crosswalks/<skill>.md`가 없어서 “heading별 포함/병합/위임/생략/source-gap” 추적표는 존재하지 않습니다.

실행한 주요 명령:
```sh
pwd -P
rg --files workspace/develop/source-crosswalks
rg --files workspace | rg 'skill|SKILL|runtime|dddjango|source-crosswalk'
find . -maxdepth 5 -iname '*crosswalk*' -print | sort
test -d workspace/develop/source-crosswalks
test -d dddjango/skills
find dddjango -maxdepth 4 -type f 2>/dev/null | sort
sed -n '37,48p' workspace/docs/reference-index.md
sed -n '18,31p' workspace/docs/skill-authoring.md
sed -n '191,213p' workspace/docs/plugin-structure.md
```

실행하지 않은 체크:
`validate_skill_docs.py` 검증은 실행하지 않았습니다. 비교 대상인 `dddjango/skills`가 없어서 runtime skill 반영 여부 검증이 의미 있게 수행될 수 없습니다.
