# dddjango Source Eval

This bucket is for source-provenance evaluation: whether runtime skill guidance can be traced back to `workspace/docs` and `workspace/reference` without hiding source gaps.

## Scope

- source coverage crosswalks
- source gap and provisional fallback tracking
- delegation, omission, and merge rationale for source headings
- source-backed review evidence for runtime skill guidance

Do not use this bucket to score final answer wording. That belongs in `eval/response`.
