dddjango skill을 실제 런타임에서 읽을 때 context가 너무 무겁거나 source 문서가 그대로 들어간 느낌이 없는지 리뷰해줘.

`SKILL.md`와 runtime reference 파일 구성이 에이전트가 필요한 자료만 골라 읽기 좋은 구조인지 보고, Django API 관련 reference가 신규 구현 기준을 흐리지 않는지도 함께 봐줘.

각 runtime reference 파일에 대해 언제 읽으면 좋은지와 언제 읽지 않는 게 좋은지도 짧게 정리해줘.

검토 근거로 본 `SKILL.md`/`references/` 구조도 간단히 포함하되, 실제 파일 링크나 절대 경로는 쓰지 말고 runtime bundle 기준 상대 경로만 적어줘. validator, eval, browser, Serena를 실행했다고 쓰지 말고, 실행하지 않았다면 실행하지 않았다고만 말해줘.
