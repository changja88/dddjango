# dddjango Plugin Acceptance Eval

This bucket keeps the older integrated plugin acceptance material that spans response quality, runtime discovery, source provenance, workflow behavior, and code-artifact smoke checks.

Use the scoped buckets for new work:

- `eval/response`: final-answer text quality and honesty
- `eval/runtime`: plugin install, discovery, metadata, cache, and host integration
- `eval/source`: source provenance and crosswalk coverage
- `eval/workflow`: process and role-map adherence
- `eval/code`: generated source, diffs, and executable checks

Do not treat this bucket as a response-only score.
