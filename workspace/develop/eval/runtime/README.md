# dddjango Runtime Eval

This bucket is for checks that prove the plugin can be installed, discovered, loaded, and exposed correctly by a host runtime.

## Scope

- `.codex-plugin/plugin.json` and local marketplace discovery
- `plugins/dddjango` symlink or directory behavior
- runtime cache sync against canonical `dddjango/`
- skill metadata exposure from the evaluated runtime
- host integration smoke checks

Do not use this bucket to score answer wording or generated Django application code.
