# dddjango Workflow Eval

This bucket is for process evaluation: whether an agent applies dddjango workflow rules at the right depth for the task.

## Scope

- TDD workflow fit
- DDD and architecture workflow fit
- subagent role-map and handoff behavior
- verification honesty
- workflow over-application on simple tasks
- workflow under-application on composite or risky tasks

Do not use this bucket to score generated source code correctness. That belongs in `eval/code`.
