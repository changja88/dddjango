왼쪽 = 흐름(도형) · 오른쪽 = 각 단계가 하는 일 + 쓰는 스킬. 스킬 색: architecture-* · implementation-* · discipline-*

시작/끝 입출력 처리(역할) 판단(게이트·루프) 호출: Claude Agent · Codex spawn_agent→wait_agent
판단(◇)에서 승인/통과는 아래로, 수정/exit2는 위 단계로 되돌아간다(주황 점선 = 되돌림 순환). 같은 지식 스킬이 여러 역할에서 재사용된다 — discipline-*·implementation-*는 감수자 전용이 아니라 작성자(tester·coder)도 로드한다. 골격은 Claude·Codex 동일 — 호출만 Agent ↔ spawn_agent→wait_agent(multi_agent=true).
