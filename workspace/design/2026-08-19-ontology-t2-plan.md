## 2. 작업 분해

### T2-0a. 프로토콜 사전 등록 (게이트 합의 대상 — 실런 전 어느 시점이든 개정은 §10급 기록)

- **판정 산식(수식 고정 — L-M #2·#3)**: 발주 o·암 x의 위반 수 `V_x,o,r`(반복 r=1,2)에서 `V̄_x,o` = 반복 중앙값(n=2는 산술평균). 판정 재료 = 밀착·혼합 층의 유효 발주(`V̄_B,o > 0`인 발주 — `V̄_B,o = 0`은 **uninformative ceiling**으로 분리·성공 산입 금지·별도 보고).
  - 방향 조건(발주별 전건): `V̄_B,o ≤ V̄_A,o ∧ V̄_C,o ≤ V̄_B,o`.
  - 감소율: `rate_o = (V̄_B,o − V̄_C,o) / V̄_B,o` — 유효 발주의 rate 중앙값 ≥ **15%**(D9)면 운영 문턱 충족. 절대차·rate ratio 병기, `V̄_B,o < 3`이면 «저분모» 플래그(1→0=100% 잡음 자인).
  - 비밀착 층(비열화 전용): `V̄_C,o − V̄_B,o ≤ δ`, **δ=0**(개정 1 문면 — 사전 등록).
  - 판정 스칼라 = 결정적 검사기 위반 수 단독(severity=violation — 계수 규약은 T2-0b scorer 계약).
- **estimand 명명(L-M #5·#6)**: B−A = «폐루프 정책 번들 효과»(루프+주입+재생성 예산) / C−B = «규칙 선별 층 효과»(동일 렌더러·동일 포맷·selector만 교체 전제 — T2-4). 두 대비 모두 발주 사례 연구로 한정.
- **암 정의(L-N L-3·L-M #5)**: 세 암 모두 **T2 개작 완료판 파이프라인**(내부 plugin·검사기·gate byte-identical). A = `loop_enabled=off`·재생성 0 / B = 루프 on·스냅숏 markdown 조인 규칙 팩 / C = 루프 on·SPARQL 선별 규칙 팩. B·C 재생성 예산 동일 N=3. 실런 판형 = 무수정 승인 고정(게이트 반송 3암 공히 0 — 반송 지표는 판정 무관·§1 ② 의무 산출물로만).
- **런 유효성 규약(L-M #13)**: 런 시작 = 독립 세션 개시. 발주별 hard stop(§3). 기술 실패(모델 오류·인프라·scorer crash) = **같은 블록의 A/B/C triplet 전체 재실행+최초 기록 보존·사유 등재**. 산출물 미완성·STOP·인수 게이트 불통과 = **판정 실패**(0위반 산입 금지 — L-M #7). intention-to-treat: 유효 런 제외는 사전 등록 사유 목록만.
- **발주 인수 게이트(L-M #7)**: 발주별 arm-independent 블랙박스 인수 테스트를 실런 전 동결(O-7=기존 고정 게이트 판형·O-4/O-5=발주문+인수 테스트 신규 저작 — T2-0b 봉인). 인수 통과본만 채점. LOC·파일 수·심볼 수를 노출량 공변량으로 기록.

## 6. 동결 개정 상정 2건 (§10 절차 — 사용자 승인 필수·실런 선결)

**개정 1 — §6 비열화 부등호 정정(L-M #3·L-N L-4)**
- 현행: «구조 이득(…) 명시 채택 ∧ **C≥B(비열화)**»
- 개정안: «구조 이득(…) 명시 채택 ∧ **V_C − V_B ≤ δ(비열화 — 위반 수 V 기준·δ는 T2 세부 문서 사전 등록)**»
- 사유: 판정 지표(위반 수)는 낮을수록 좋으므로 현행 부등호는 자기모순 — 문자 그대로 집행하면 C가 B보다 나빠도 승인 가능. δ는 본 계획이 0으로 사전 등록.

**개정 2 — §8 T2 행 개작 범위 정정(L-M #16·L-N L-2)**
- 현행: «B트랙 완성: **11종 개작**+Findings 공용화+registry_gate 하위 호환»
- 개정안: «B트랙 완성: **공용 구조화 출력 모듈 27종 체계**(완료 2종+잔여 25종 개작)+registry_gate 하위 호환 — 채점 scorer도 이 27종 체계. **선행 계약 6종의 Work 조인은 T3 이월**(contract_ref 적재·위반 그래프의 Work 조인은 규칙 발견 한정)»
