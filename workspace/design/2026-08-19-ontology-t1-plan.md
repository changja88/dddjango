### T1-2. 저작 규약 확장 + T0 스택 정비 (authoring §13~§16 신설 — 이관 공정의 사전 확정)

**§13 블록 경계·공백 소유 규약** (L2-1 처분 — 라운드트립의 근간):
- 블록 리터럴 = **원문 스팬 verbatim**(문장 내부 경질 개행 포함). 블록 간 구분자(공백·개행·빈 줄)는 **선행 블록의 후행 스팬에 귀속**. 렌더 = 단순 연결(구분자 삽입 0) → byte 등가가 구조적으로 성립.
- 리스트 항(«- »·«1. »)·blockquote(«> »)는 마커 포함 verbatim으로 norm/prose 블록에 귀속(kind 확장 불요). checklist-item은 체크박스 형태(«- [ ]») 한정.
- kind-code 리터럴 = **여는 펜스~닫는 펜스 전체 라인 verbatim**(언어 태그 포함 — closed 셰이프에 별도 자리 불요). 표 머리행·구분행도 table-row(계수 2축에서는 데이터 행만 산입).
- 소비 시 trim(재진술 대조·규칙 팩)은 T2 소비층 몫 — 정본 리터럴은 verbatim 불변.
- red/green 픽스처 3벌(경질 개행 문장·한 행 다문장·문단 경계) fixture 레인 편입.
- 부수 규약: 이관 전 **preflight**(원문 NFC·LF·탭 스캔 — 위반 시 원문 선정정 커밋 후 이관).

**§14 절/블록 IRI 인코딩** (E6 실장 + L2-8 처분):
- 절 IRI = djr 기저+`s/`+문서 경로+`/`+절 키(§앵커+서수 — 서수는 등장 순, 신규 삽입 충돌 시 새 절만 다음 미사용 서수·절 키 대장=원장 겸용). 블록 IRI = 절 IRI+`/b`+서수. 무앵커 절 `(전문)`.
- **폐쇄 인코딩 집합**: 공백·`#`·`%`·`` ` ``·`<`·`>`·`"`·`{`·`}`·`|`·`\`·`^`·C0/C1만 percent-encoding(**`%` 자기 포함 — 가역성**), 한글·`§`·`·`는 원시(RFC 3987 ucschar). NFC 고정. 왕복 항등 픽스처.
- **게이트 ② 확장(T0 개작 1)**: djr 네임스페이스 IRI의 fragment 문법 검사(정규식 — rdflib가 위법 IRI를 무저항 통과시킴이 실측됐으므로 기계 백스톱 신설).
- 전 절/블록·Expression IRI는 `<전체 IRI>` 표기(T0 직렬화기 규약). 채번 시점 헤딩 스냅숏 불변(현행은 headingCurrent).
- **headingSnapshot = 헤딩 라인 전체 verbatim**(`### 6.2 …` — 레벨 포함, 렌더가 라인 재생성 가능). `djr:parentSection` 채택(절 트리 질의 — 어휘 개정 절차 경유, 안정화 선언 전).

**§15 이관 공정 절차서** (§4-2 실장 — 파일럿이 첫 실증):
- ⓪ preflight(§13) → ① LLM 블록 분해(kind 5종·순서 채번·스팬 소유 규약 준수) → ② 규범 블록 식별+**Work 채번(ISSUED — 시작값 R-0001, 경로 필드=`rules/<문서 키>.ttl`)+초기 Expression 채번**(`R-NNNN@이관일`·`djr:revision 1`·`prov:specializationOf`·`djr:currentExpression` — 개정 1 3노드형) → ③ wiring 저작(아래 §16) → ④ Section(headingSnapshot·sectionOwner·parentSection)·Document 노드 → ⑤ 4단 게이트+SHACL+**계수 기대표 갱신**(diff가 이관 절 계수와 대조 가능해야 — 무규율 갱신 금지) → ⑥ 렌더 라운드트립 대조 → ⑦ 검수 패키지.
- 재진술: 정본 1곳 Work 승격+`djr:restates`. **상대 블록이 미이관 절(그래프 밖)이면 restates 생략+원장 비고에 유예 기록(T3 소급 연결)** — 파일럿 실물(§6.2↔§2.2 축자 쌍)이 이 케이스.
- 공정 기록: 전 파일럿 절의 게이트 반송·수리 루프 횟수·검수 반송을 gate-report 로그로 집계(**CNL 결정 재료** — T2 게이트 §4-6).

**§16 wiring 저작 규약** (L3-3 처분 — 기계 참조가 아니라 판단 작업):
- enforcedBy 저작 = **4원 종합**: ① 규범 문면의 역할명(«schema checker» 등) ② 검사기 docstring의 § 인용 ③ P0 «커버» 판정 ④ registry #N 대응 — 근거를 검수표에 기록(저작 근거 의무).
- **역할명→검사기 파일명 매핑 표**를 T1-2에서 확정(ninja §6.2의 역할명 2종+marker 2종 → 실물 3종 대응 — E07 추론의 승격 확인).
- **위임 기본값 표**(문서군→기본 Agent — rule-owner-map ⓓ 관례): 검사기 비커버 규범의 delegatedTo 대상을 표로 확정(임의 저작 금지).
- **`wiring/registry.ttl` 신설**: Checker 27종+Agent 개체의 공유 선언(문서 횡단 — 게이트 ④가 wiring 전량을 병합하므로 공유 파일로 해소).
- **게이트 ④ 병합 확장(T0 개작 2 — L3-1 blocker 처분)**: ④(훅 포함) 데이터 그래프 = 변경 파일+vocab+wiring+**rules 전량**(교차 참조 restates·aliasFor의 위양성 red 해소 — 스크래치 실험 실증). authoring §2 문면 동반 갱신.
- **셰이프 개정(어휘 개정 절차 §7 경유 — 안정화 선언 전)**: BlockShape-text = sh:or(rdf:langString·xsd:string) + 저작 규약: norm/prose/checklist=`@ko`·code/table-row=`xsd:string` + kind↔datatype 정합은 SPARQL 검사(T1-6 도구).

### T1-3. 파일럿 이관 (해상도 대조 저작 포함)

### T1-4. 렌더러 + 동기 검증기 + 미러 실개작 (한 커밋 — 커밋 앵커 통일)

- **렌더러** `ontology_render.py`(.venv): 블록 순서 연결(§13 — 구분자 삽입 0). 혼합 파일 조립: sectionOwner=graph 절 구간만 render 출력, 산문 절은 현행 파일 소스(절 경계=헤딩). **마커**: 절 헤딩 직후 1행, 문면 고정(`workspace/` 경로·`#숫자` 미포함 — corpus_lint 오탐 회피, 파일 선두 금지 — preamble 파서 exit 3 회피).
- **등가 판정(게이트 2-1의 통과 조건)**: **마커 라인 제거 후 byte 등가(잔차 0)**. 층① 정규화·잔차 4등급(일치/정당/신규-표현/신규-규범)은 **실패 시 진단 분류 전용**(통과 대체물 아님). 층① 구현은 T1 신설(연산 목록+골든 쌍·코드 펜스 비적용).
- **동기 검증기** `ontology_render_sync.py`: «투영물==render(그래프)»(그래프 소유 절 한정). SyncDebt 등재 절 경고 강등·미등재 불일치 red. verify-ontology [7] 편입. **릴리즈 잔량 0**: release 레시피에 `--release`(SyncDebt 잔량 0) 별도 단 1줄(D1 단일 출처 불훼손).
- **골든 2건**: ① 그래프 소유 절 렌더 산출물 수기 수정 → red ② 산문 소유 절의 정상 편집 → **green**(어느 온톨로지 게이트에도 안 걸림 확인 — corpus_lint는 위생 lint지 수정 검출기가 아님을 자인). fixture 레인 편입+스모크 확장.
- **훅 확장(T0 개작 3)**: pre-commit 트리거 2축 — ① ontology ttl(기존) ② 코퍼스 md 변경 시 **stdlib 검사만**(ledger 부식 대조+그래프 소유 절 무단 수정 — 원장 TSV 기반·.venv 불요, SyncDebt 등재 절은 경고). 렌더 full 검증(rdflib)은 verify·릴리즈 2점 — 절충임을 자인(§4-4의 훅 축을 stdlib 범위로 실장).
- **미러 실개작**(동결 §9 «T1부터 그래프 소유 절 스코프 제외(inv1)» 준수): corpus_mirror_sync에 **원장 기반 절 스팬 절제 비교** 신설+`--write` 스팬 보존 병합+STRUCTURE(exit 3) 회귀 케이스 — «최소 개작» 아님을 자인하고 작업량 등재. inv2(codex byte-exact)는 기존 `--write` 동반 갱신으로 유지(T4 대체까지).
- **한 커밋 규율**: 동기 검증기 가동+파일럿 절 소유 전환+미러 스코프 처분 = 동일 커밋(동결 §8 «도입과 동일»·중재 G «전환과 동일» 두 문면 동시 충족).

## 6. 리스크·중단 처분

- **라운드트립**: §13 스팬 소유 규약이 byte 등가를 구조적으로 보장(구분자 삽입 0) — 남는 위험은 LLM 분해의 스팬 누락뿐이고 등가 검사가 즉시 잡는다(은폐 불가).
- **이관 LLM 오류**: 4단 게이트+SHACL(형식)+검수 배치(의미)+등가 검사(무손실) 3중. 파일럿에서 오류율 실측→T3 반영.
- **게이트 ④ rules 전량 병합의 성능**: 파일럿 규모(수백 트리플)에서 무시 가능 — T3 규모에서 재평가(문서 단위 캐시 등은 그때).
- **T1 중단**: 파일럿 절 «렌더본 산문 정본 재선언» 한 걸음 복귀(T1-6 리허설이 사전 실증). 센서스·원장·도구는 무해 존치, ISSUED 채번분 tombstone, 미러 개작은 스코프 제외 절이 0이 되므로 자연 무효.
