## 0. 한 줄 설계

**규칙 코퍼스의 정본을 RDF 그래프(Turtle 저작)로 전환하고, 그 위에 «정본 검증(SHACL) → 산출물 판정(결정적 검사기) → 위반 그래프 → 위반 레코드만 든 재생성 → 렌더 투영 소비 → 선별 주입»의 폐루프를 만든다.** 품질 이득의 본체는 포맷이 아니라 이 폐루프라는 것이 조사의 수렴 결론이며, 그 정량 근거는 인접 도메인 외삽뿐이므로 이 저장소 자체의 A/B(§6)가 근거를 닫는다(§1 자인). 에이전트는 Turtle 원문이 아니라 렌더된 투영물을 소비한다.

## 1. 목표·지표

**측정원 배정표** (같은-자 순환 방지): **품질 판정은 §6 A/B 전용.** 위반 그래프 시계열은 운영 관측 전용 — 눈금(검사기 수×이관 규칙 수)이 T1~T4 동안 계속 자라므로 증감 해석에는 눈금 정규화+변경 이벤트 주석을 필수 동반한다.

- **1차 — 산출물 품질(규칙 준수율)**, A/B로만 판정:
  - ① **결정적 검사기 위반 수**(주 지표 — 처치 범위인 coder 산출물로 슬라이싱).
  - ①′ 보조: discipline-reviewer가 잡는 위반 수 — reviewer 산출에 **기계 가독 위반 레코드**(규칙 참조·대상·근거)를 의무화해 위반 그래프의 제3 입력원으로 편입하고, 확률 변동은 반복 k회 합집합/중앙값으로 통제. §6의 «LLM-judge 배제»는 **자동 평가 점수를 품질 판정에 쓰지 않는다**는 뜻이며, reviewer의 위반 «발견»은 규칙 인용으로 사후 검증 가능한 발견 채널이라 배제 대상이 아니다. 위반 동일성(규칙×대상 파일×심볼)·오탐 처분·심각도 계수 규약은 §6에.
  - ② 사용자 게이트 반송 횟수 — **A/B 품질 판정에서는 보조 지표**(생성원이 암 정체를 아는 비맹검 사용자 본인이라 판정 규칙에 산입 금지. 반송 시 규칙 인용 의무로 재량 폭을 기계적으로 축소). 한정 정의: 재생성 루프의 내부 회전은 별도 계상(산입 금지 — 루프 자체가 처치라 교락). 계수기는 세션 jsonl 결정적 파생(T2 산출물).
- **운영(진도) 지표 — 품질 판정 재료 아님**: 기계 판정 비율(enforced 커버리지)·이관 진도. 검사기 증설·이관 진도에 기계적으로 비례하는 산출량 지표임을 자인하고 강등.
- **부수**: 암별 **총 토큰**(원시·비용 가중 병기, 루프 회전 주입 산입 — 주입 채널만 세면 루프 비용이 장부에서 사라짐). 참고 근거의 -71%는 제약부 한정(전체 프롬프트 25~30%)·산문 vs 구조화 인코딩 비교이므로 그대로 전이하지 않는다. 세션 시간은 session_telemetry 정의 준용(에이전트 실행 구간 합, 게이트 대기 제외).
- **자인**: «규범 그래프→코드 생성 준수율»의 직접 선행 증거는 부재(Q4 — 인접 도메인 외삽뿐). §6 A/B가 근거를 닫는 유일한 길이며, A/B 없이 완료 선언하지 않는다.

| **E8 위반 = 1급 데이터** | 검사기 27종+SHACL+reviewer 레코드의 출력을 위반 개체 그래프(규칙 Work IRI+Expression·대상 파일/심볼·심각도·근거)로 통일. **통일 수단은 검사기 공용 구조화 출력 모듈의 재저작**이다 — 실물은 출력 규약 준수 16/27, 규약 밖 11종 개작+지역 Findings 클래스 16벌 공용화+registry_gate `[#N]` 라인 하위 호환이 T2 산출물(어댑터 한 줄이 아님). 규칙 IRI 조인은 검사기 «담당-규칙» docstring 블록의 IRI 표기 재저작(27종 전수 — 통일 정형구는 실측 8~10종뿐). 개작 범위 재실측(개정 4와 동일 취지): 공용 모듈 편입 기준 완료 2종+잔여 25종 = 27종 체계 — 본 항의 «규약 준수 16/27·규약 밖 11종» 집계는 `[#N]` 라인 규약 기준의 과소 산정. 위반 피드백 재생성은 «위반된 제약+핵심 맥락만» 간결 주입(인접 도메인 실증 — KG 수리·질의 수리(VIO·OBQC), 직접 증거는 §6이 생산), 전체 규범 재주입 금지. 무접두 #N 축의 주입 재료는 «번호+검사기 산출 발췌»로 한정(본문 정본 미동봉 — E6). 모델 성향을 거스르는 하우스룰은 결정적 검사기 확장 대상으로 우선 편입 — 실측 비커버 축부터: tdd 스킬 완전 공백(스크립트 연결 0)·human 판정 2건(#254·#316) 등 | Q4·Q2·Q1 + 리뷰 G·F·P |

## 4. 이관 전략

1. **전환 단위 = 절 유형**: T1 선행 작업으로 606절의 절 유형 센서스(참조성/서사성 — 혼합 절은 문장 단위 분류 허용, v2 worst-of 관례 이월) + **codex판 절 대응 센서스 병행**(T4 잔차 규모의 사전 파악). 센서스 산출물은 T1 게이트에서 **동결** — 이후 재분류는 개정 블록+사유+T3 리포트 전량 명세 의무(재분류로 100%가 자동 달성되는 구멍 봉쇄).
2. **이관 공정**: LLM이 절→블록 시퀀스 분해+규범 블록 식별 → 4단 게이트+SHACL → 소유자 검수 배치(**상한 ≤250 규범 문장/배치** — 절 수 상한은 밀도 50배 편차로 무의미). 원문 verbatim 보존(블록 모델이 보장). 검수 항목: 규범 블록 식별 적정·재진술 병합·alias 공간 귀속.
3. **커버리지 절 단위 원장**: 전역 상수 3,217이 아니라 절마다 {이관 시점 원문 doc_hash, 이관 블록 계수(문장+비산문 운반체 2축), 잔존 표기}를 등재. 미이관 절의 원문 변경 시 해당 절 재검토 exit 2(전환기 분모 부식 방지). 미이관분은 «산문 정본 잔존» 명시, 자동 소실 없음. 기준선 2원화: 플러그인 코퍼스 / 모노레포 명세(무접두 #N — 범위 밖, E6).
4. **핫픽스 절차**(산문 직행 압력의 합법 경로): 긴급 시 산문(렌더 산출물) 선반영 허용 + 채무 등재 + **다음 릴리즈 게이트가 채무 잔량 0 요구. 비차단 조항(v2 D4 명시 이월)**: 동기 검증기는 채무 대장에 등재된 절의 불일치를 훅·verify에서 **경고로 강등**(커밋 비차단 — 등재 없는 불일치만 red), 릴리즈 게이트에서만 잔량 0 차단. 채무 레코드는 위반 개체와 **별도 클래스**(`djr:SyncDebt` — 어휘 v1에 포함, T0)로 등재한다. 사후 검출+강제 back-port가 훅 우회의 방어선.
5. **전환기 SLO**: T1~T3 이관 배치 간 최대 간격 2주. T2 실패 분기는 §8 종료 조건.
6. **CNL(통제 자연어) 게이트웨이**: 규범 문장의 문형을 제한된 패턴 집합으로 저작하게 해 **산문↔Turtle 왕복 변환을 기계 검증 가능하게 만드는 저작 게이트**(ArchCNL 선례 — Q2). 채택 여부는 **T2 게이트에서 결정**(판단 기준: 파일럿 이관 실측 — 문형 제한의 저작 비용 대비 수리 루프·검수 감소. 단일 시점 — T5에서는 «운용 평가»만).

## 6. 측정 (A/B — 근거를 닫는 장치)

동결 문면으로 확정하는 하중 파라미터(세부 문서는 수치 채움만 — 설계 자체가 리뷰를 우회하지 않도록):

- **3암 설계**: **A** = off(현행 파이프라인) / **B** = 폐루프만(그래프 미경유 — rule-owner-map+검사기 출력으로 구성한 규칙 팩+위반 재생성) / **C** = 폐루프+그래프(SPARQL 선별 규칙 팩). 그래프 고유 기여 = C−B. B트랙 부품은 T0 병행 트랙으로 선행 구축(§8 — 그래프 실패 시에도 독립 가치).
- **측정 종료점(개정 7)**: 품질 채점의 종료점은 G2 승인이 **아니라**, 암별 처치가 끝난 뒤 arm-independent 인수 테스트와 frozen scorer 를 새로 실행해 완료한 **공통 post-treatment checkpoint** 다. 세 암 모두 같은 checkpoint 에서 측정하며, **G2 제시·승인은 어느 암에서도 채점 요건이 아니고** `pipeline_complete` 로 따로 기록한다. 사유: 파이프라인은 귀속 red 가 남으면 G2 를 제시하지 않으므로(commands 7번), G2 를 채점 요건으로 두면 **A암이 나쁠수록 판정 실패로 탈락**해 비교군이 소실된다. 상세 절차(`S0` 봉인 → 암별 처치 → `S1_x` 봉인 → 공통 재실행 → 채점)는 t2-plan §2 T2-0a.
- **판정 규칙(사전 등록)**: 발주당 조건당 **반복 ≥2**. **품질 판정 = ①(결정적 검사기 위반 수) 단독** — 방향 일치 + 중앙값 감소율 문턱(수치는 T2 세부 문서에서 사전 등록 후 실행). ①′·②는 보조 참고로만 병기(판정 규칙 산입 금지 — ②는 비맹검 생성원, ①′는 확률 판정기). 사용자 판정은 «사전 등록 규칙의 통과 확인»으로 한정. **T3(전량 이관) 정당화 = «C−B 우위» 또는 «구조 이득(미러 소멸·개정 기계화·ID 통합) 명시 채택 ∧ V_C − V_B ≤ δ(비열화 — 위반 수 V 기준·δ는 T2 세부 문서 사전 등록. 개정 3)»** — 후자 선택 시 그 선택을 게이트 기록에 남긴다. **층화 비대칭 처리**: T2 시점 그래프는 파일럿 범위뿐이므로 비밀착 발주에서 C암은 미이관 규칙에 대해 B암과 동일 재료로 폴백하며, **C−B 대비는 밀착·혼합 층 한정**(비밀착 층은 비열화 검사 전용).
- **발주 통제**: T1 이관 범위 확정 전에 발주 후보 풀 사전 등록(선정-처치 독립), 층화 = 이관 클러스터 밀착 1·비밀착 1·혼합 1. **발주 소스는 실제 백로그 우선**(합성 발주는 표기). 결과 일반화 한정 문구를 게이트 판정문에 내장. **운영 비용**: 3암×층화 3발주×반복 ≥2 = 최소 18 실런 — 소유자 시간 상한과 비용·기간 산정을 T2 세부 계획의 게이트 합의 필수 항목으로 한다.
- **실런 격리**: 암마다 청정 워크트리+도구·모델 버전 스탬프 고정, 메모리·지식 그래프 상태는 동일 스냅숏, 실행 순서 상호 균형, 암 1회 = 독립 세션 1개(session_telemetry 세션 경계 준용). **B암 재료 고정**: B암 규칙 팩은 T0 시점 rule-owner-map 스냅숏으로 고정 — §9의 배선 재지정(map의 투영화)이 실런보다 먼저 일어나면 «그래프 미경유»가 거짓이 되므로, 재지정은 3암 실런 이후로 순서를 고정한다(§8 T2).
- **계수 규약**: 위반 동일성 = 규칙 Work×대상 파일×심볼, 오탐은 판정 기록 후 제외, 심각도별 분리 집계. reviewer 위반은 기계 가독 레코드(①′)만 계수.
- T5의 «상시화» = 주기적 미니 A/B(순환 시계열 복귀 방지 — §1 배정표).
- LLM-judge류 자동 평가 점수는 품질 판정에 쓰지 않는다(§1 ①′의 한정과 함께 읽음).

- **롤백 안전망**: 렌더 투영물은 항상 완전한 산문 문서로 존재 — 중단 시 «최종 렌더본을 산문 정본으로 재선언» 한 걸음으로 복귀(T1에서 리허설 1회, T2·T4 완료 기준에서 경로 재확인). **중단 처분 목록**(v2.1 ⑪ 이월): 중단 시 docstring IRI 표기·위반 어댑터·질의 카탈로그·ISSUED의 처분(존치/tombstone/스코프 종료)을 각각 선언하고 실행한다 — B트랙 산출물(위반 어댑터·루프)은 그래프와 무관하게 유지.
