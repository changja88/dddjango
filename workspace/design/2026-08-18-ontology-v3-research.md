## 수렴 지점 (복수 레인 일치 — v3 골격)

1. **이원 구조 고정** (Q1·Q2·Q6·Q7): 그래프=규칙의 구조·관계·메타 정본 + SHACL=코퍼스 무결성 게이트. **규범 집행은 결정적 검사기**(기존 27종+확장)가 담당 — OWL 추론에 집행을 맡기는 설계는 20년치 실패 선례 위에서 배제.
2. **품질 이득의 본체는 폐루프** (Q4·Q2·Q1): 규칙↔검사기↔위반의 삼자 배선 + 위반 레코드만 들고 재생성. 포맷 전환 자체는 준수율을 안 올린다(측정된 사실) — v3의 가치 서사를 여기에 건다.
3. **정본은 Turtle, 소비는 렌더 투영** (Q7·Q4·Q5): 에이전트는 Turtle 원문을 읽지 않는다. 단건 조회=렌더 markdown 실독(현행 소비 방식 보존), 횡단 질의·주입 선별·위반 배선만 SPARQL. 이건 후퇴가 아니라 업계 표준 구도(FIBO·schema.org도 소비는 투영물).
4. **하이브리드 산문 모델** (Q5·Q7·Q2): 규범문 본문은 그래프 안 한국어 리터럴(자체 주석 어휘)로 보존 — 형식화 손실 방지. 서사 산문은 그래프 밖 수기 존치. 순수 전량 형식화는 선례도 없고 뉘앙스 손실로 역효과.
5. **저작 파이프라인 기계화** (Q3·Q1): 정본 직렬화 강제, 4단 게이트, blank node 금지, 골든 페어 회귀, 도구 버전 고정, pySHACL 정본 판정기 고정.
6. **정체성·개정 표준 착지** (Q2): v2의 ID·개정 3분류 개념이 표준 어휘로 — 불변 Work IRI + 시점 Expression + PROV-O 개정 이벤트 + OBO 폐기 관례.
7. **이중 편집점 금지** (Q7·Q5·Q3): 단방향·자동·결정적 렌더 + 투영물 직접 편집 금지 + CI 동기 검증 + 전환기 절 단위 정본 소유 표식 + 전환기 최단화.
8. **측정 내장 필수** (Q4·Q2): 이 설계의 최종 근거(규범 그래프→생성 준수율)는 세상에 직접 증거가 없다 — dddjango 자체 A/B가 근거를 닫는 유일한 길.

## 긴장 지점과 해소

| 긴장 | 해소 |
|---|---|
| «표준 스택 전면»(사용자 선택) vs «Turtle은 LLM 소비 표면 부적합»(Q7 계측) | 정본·검증·질의는 표준 스택 전면, **소비 표면만 렌더 투영** — 스택 채택 범위의 문제가 아니라 배선의 문제 |
| «최대 적용» vs «검사기가 소비하는 구조만 만든다»(Q7 과공학 함정) | 최대 적용의 방향을 «공리의 깊이»가 아니라 **«배선의 넓이»**(정본→검증→위반→재생성→렌더→주입 전체 폐루프)로 정의 |
| «표준 스택» vs «OWL 추론 배제 권고»(Q6·Q2·Q7 일치) | OWL 추론은 «표준 스택의 필수 부품»이 아니다 — RDFS+SHACL+SPARQL이 표준 스택의 실무 본체(업계 수렴). 추론기는 비채택 기본값+필요 실증 시 CI 국소 채택 |
