## 2. [A] 이 결함의 원인 (v0.1.0 런의 인과 — 확정)

### 문제 1 — 요소별 값 배정 어긋남

- **A1 (입력 공백 — 요소↔값 결합 부재)**: 목표는 Expo CSR — 카드 콘텐츠(태그·제목·배지)의 요소별 실값은 어떤 정적 동결로도 얻을 수 없고(R3 재확인), SSR 셸 요소(헤더·칩)는 결합이 동결본에 실재하나 **절단 도구가 클래스↔규칙 조인을 풀지 않는다**(R1 F4 — 도구는 값 주머니만 절단). 나아가 도구 수집 축에 **font-weight·text-align·line-height·font-family 자체가 없다**(R2 — CSR 무관 보편 공백·웨이트/정렬 어긋남의 독립 설명). 값 «풀»(font-size 17종 메뉴)은 절단 가능함을 본 세션 실험으로 확인 — 그러나 **배정 근거가 0비트**라 완벽 집행으로도 요소별 선택은 눈대중이다(빈도 정렬은 원자 CSS에서 무의미). → «크기 전수 연결» 3중 채널(architect 인용 의무·전수 처분·리뷰 ⓑ)은 메뉴 축만 커버 — **구조 공백 확정**.
- **A2 (G2 실효 부재 — 문제 2와 공통 원인, R3 §5 통합)**: v0.1.0의 G2는 «나란히 육안 대조» 한 줄 — 대조 범위 지시·증적 필드(`g2_visual`) 부재로 **수행 여부조차 확인 불가**한 구조였다. 육안 분해능은 원인이 아니다 — 매크로 차이 3건(정렬·배지 위치·패널)은 나란히 대조만으로 명백하고, 결정적으로 **이 신고 자체가 사용자 육안**이다(분해능이 한계였다면 신고가 없다 — R3 §2). 마지막 방어선은 G2 시점이 아니라 납품 후에 작동했다.

### 문제 2 — 하단 고정 무력화

- **A3 (규범 공백 — 유일한 구조 원인)**: 코퍼스 전판(v0.1.0·현행 공히)에 overflow·sticky·fixed·배치 거동 규범 0건(R2 확장 grep 재검증 — 유사 어휘 포함). `.saju-shell{overflow:hidden}`은 coder 자체 발명이고 막을 규칙이 없었다.
- **A4 (백스톱 사각)**: 24종(WS8·WI4·WN8·WP5)에 CSS 배치·기능성 검사 0건 — CSS 내용 검사는 WP4 색 리터럴 정규식뿐(치수 리터럴도 미집행 — R2).
- **A5 (문면 검토의 구조 사각)**: 선언(`position:sticky`)과 무력화(셸 규칙)가 원거리 분리 — 정적 문면 검토(리뷰어 2종은 코드를 안 보거나 시각 판정을 G2에 위임)가 잡기 어려운 형태.
- **A2 (공통)**: 위와 동일 — «스크롤 중 고정 유지»는 육안으로 자명하나 G2가 실효하지 않았다.

## 3. [B] 현행 코퍼스의 전방 위험 (런 원인 아님 — 재발 방지 대상)

- **B1 (허위 능력 서술)**: architecture-web final.md:129 «HTML 경로는 절단 도구의 computed 명시화가 이를 대신한다» + 커맨드 :121 동취지 — 7412365에서 최초 도입된 문장으로 **도구 실물에 그 능력이 없다**(코퍼스 전체에서 'computed'는 이 두 문장뿐 — R2). 다음 런의 설계자가 실측 보완 필요를 인지하지 못하게 오도한다.
- **B2 (G2 개정 문면의 잔여 한계)**: 7412365 강화(전 구간·서체·간격·개발자도구 권장·g2_visual)는 실집행 0회 — 강화가 충분한지 미검증이고, 요소 단위 **기계 대조 채널**과 «스크롤 중 고정 유지» 관찰 항목은 여전히 없다.
- **B3 (관찰 판형의 배치 거동 미명시)**: motion-notes 문답의 «스크롤 시 무엇이 변하나»는 열려 있어 자리가 아예 없진 않으나(R2 — v1의 «자리 없음»은 과강), 우산 정의·효과 필드(duration/easing)가 모션 전제라 스크롤 고정 수확이 우연에 기댄다. 분류 축(CSS|러너|한계)은 재현 수단 분류라 sticky는 CSS 칸에 수납 가능(v1 논거 철회). **주의 — 이 공백은 문제 2의 원인이 아니다**(sticky 의도는 채널 없이도 명세에 도달했다 — R3 §4): 전방 보강일 뿐이다.

## 5. 수정 방향 (계획 입력 — 근거 재배선 반영)

1. **목표 실측 채널 신설**(A1 봉합 — 필수): 실서비스 재현 시 목표 페이지의 요소별 computed 실측(사용자 브라우저 콘솔 스니펫 → JSON 동결·요소는 텍스트 조인) + **고정(fixed/sticky/오버레이) 요소 목록 포함**. D12v2와 무충돌(관찰 도구는 산출물 밖 — R2·거처는 web/static/js/ 금지).
2. **G2 결정적 대조 채널**(A2 봉합): 같은 스니펫을 구현물에 돌려 목표 실측 JSON과 기계 diff — 근거는 «분해능»이 아니라 **수행 품질과 무관한 결정적 증적**(R3). + «스크롤 중 고정 유지» 관찰 항목 1줄.
3. **배치 거동 규범 신설**(A3·A5 봉합 — 필수): implementation-ui 스크롤 고정 오버레이 판형 + **sticky/fixed 조상 사슬 한정 overflow 금칙**(셸 클립은 `overflow-x: clip` — 스크롤 컨테이너 비생성·visible 강등 없음 검증됨. 전역 hidden→clip 치환 금지 — BFC 차이·ellipsis 인터롭은 사슬 한정으로 원천 회피, R1 §2). houserules 성문.
4. **코퍼스 사실 교정**(B1 — 필수): «computed 명시화» 2곳을 도구 실능력(빈도 후보 절단·수집 축 5종·요소 결합 없음)으로 정정.
5. **관찰 판형 소폭 확장**(B3 — 전방 보강·원인 수리 아님 명시): motion-notes 문답에 스크롤 고정(pinned) 항목 명시.
6. **백스톱 검토**(A4): sticky 무력화 결정 검사 가능성 검토 — CSS 단독으론 DOM 조상 불가지라 과적합 위험, 불가 판정 시 리뷰어 감사 단서 성문(#462 판례).
