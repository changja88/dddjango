### W3-M2 `--debt-residual` 이 읽는 정형 행의 계약이 없다 — 누적·재상정·요구 키·빚 0

  - `요구 키: <C<n>… | ->`.

  - M = (마지막 G0 절의 ⓐ ∪ 요구) − (그 뒤 재상정 키). `-` 는 M=0 · exit 0 이다.

- **원칙 필터**: 새 장치 없이 v4 가 이미 둔 판정기의 입력 표기만 정한다.
