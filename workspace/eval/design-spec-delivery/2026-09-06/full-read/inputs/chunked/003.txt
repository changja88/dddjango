- **행위**(판정은 루트가 소유 — 인프라로 복제 금지 §3.2 빈혈 차단):
  - `Visit.open(key) -> Visit` — 새 방문(stage `idle` · `version 0`·`persisted_version 0` = **미영속** — `open()` 직후 저장하지 않는다; 첫 저장은 점유 성공 또는 S2 이월 놓기(`carry_request` — 목표 방문 선행 생성 §5.18 ①) 둘 중 먼저 오는 것).
  - `mark_persisted() -> None` — 저장 성공 직후 리포지토리가 부른다(`persisted_version = version` · version 무변).
  - **version 규약(루트 소유 · §7.3)**: 루트는 `version: int`(변경 메서드마다 `+= 1` — 한 attempt에 여러 변경 메서드를 불러도 된다)와 **`persisted_version: int`**(리포지토리가 로드 시 저장된 version으로 채우고, `open()`은 0 · 저장 성공 뒤 리포지토리가 `mark_persisted()`를 불러 `version`과 같게 맞춘다)를 함께 든다. 리포지토리 가드는 산술이 아니라 **`WHERE version = persisted_version`**이고 INSERT는 `persisted_version == 0`일 때다 — S1+에서 한 attempt에 루트 변경 메서드 둘을 불러도 깨지지 않는다. 루트가 version을 올리지 않은 호출(`REJECTED_IN_PROGRESS`·`end_turn → False`·`reconcile → False`)은 `save`를 부르지 않는다(불필요 왕복 — 정확성엔 무관). 첫 영속은 INSERT(version은 그때의 값 — S0 점유 뒤 1).
  - `begin_turn(turn_id, now, deadline) -> TurnAdmission` — **턴 진입 점유**(발주서 §5.27 ②): ⓐ `lease is None` → 점유 → `TurnAdmission(kind=ADMITTED, rewind=None)` ⓑ `lease`가 있고 `lease.is_stale(now)`(= `now ≥ lease.deadline`)이면 **되감기**(§3.3) 후 점유 → `TurnAdmission(kind=ADMITTED_AFTER_REWIND, rewind=RewindRecord{previous_turn_id, previous_stage, released_reservation_id})` ⓒ 그 밖(살아 있는 점유 — 같은 `turn_id`여도) → `TurnAdmission(kind=REJECTED_IN_PROGRESS, rewind=None)`(**상태 무변 · version 무변**). ⓐⓑ만 `version += 1`(되감기+점유를 합쳐 1회). 되감기 사실은 값(`RewindRecord`)으로 돌려주고 응용이 그 값으로만 운영 로그를 쓴다(도메인은 로거를 모른다 · 응용의 판정 복제 0).
  - `end_turn(turn_id, outcome: TurnOutcome) -> bool` — 이 턴이 점유자일 때만 점유 해제 + `last_turn_outcome = outcome` + `version += 1` → `True`; 다른 턴이 점유 중이거나 점유가 없으면 **no-op·`False`**(stale 되감기 뒤 늦게 끝난 옛 worker 보호 · 응용은 `False`면 저장하지 않는다).
  - `reconcile_pending_card(present_call_ids: frozenset[str]) -> bool` — 대본에 슬롯 `call_id`의 `function_call`이 없으면 슬롯 폐기 + `stage: SELECTING → IDLE`(불변식 유지) + `version += 1` → `True`(§5.22 ⑦ 슬롯↔장부 정합); 슬롯이 없거나 살아 있으면 `False`(무변 · 저장 0).
  - `pending_call_id() -> str | None` — 슬롯 `call_id`(응용이 내부 구조를 더듬지 않게 캡슐화 — 원칙 02).
  - `notice_language(operating_language: str) -> DisplayLanguage` — 캐시 또는 운영 언어(§4.3 ③ 폴백의 단일 소유 자리).
  - `place() -> VisitPlace` — `character_id`로 `room`/`counter` 판정.
