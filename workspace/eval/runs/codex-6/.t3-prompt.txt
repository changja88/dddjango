dddjango 파이프라인으로 이 프로젝트(catalog 앱의 Product 모델)에 한 기능을 추가해줘.

기능: 재고를 예약(reserve)하는 API — 상품 재고가 요청 수량보다 부족하면 409로 거절하고, 충분하면 그만큼 차감(예약)한다. 대상은 기존 catalog 의 Product.

[비대화형 실행 안내] 이 세션은 codex exec 비대화형이라 게이트에서 사람에게 되물을 수 없다. 각 게이트는 표준의 기본 판단을 자율로 적용해 통과하고, 설계(Phase 1) → 구현(Phase 2, TDD)까지 끊김 없이 완주해줘. 사전 승인된 게이트 답:
- 바운디드 컨텍스트 배치: 표준 원칙(판정·불변식 소유)에 따라 네가 판단해 결정한다.
- 활성 lens: ddd + db + api.
- 스코프: 네 제안대로.
- API 스택: 표준이 정한 기본대로 결정한다(내가 특정 스택을 강제하지 않는다).
- 테스트 러너: 네 제안대로.
- G1(설계)·G2(구현) 승인 게이트: 리뷰가 깨끗하면 승인된 것으로 간주하고 다음 단계로 진행한다.

완료 후 manage.py check / makemigrations / migrate / test 를 실행해 통과를 확인하고, 생성·이주한 파일과 핵심 결정(BC 배치·API 스택)을 한 단락으로 요약해줘.
