# 재고 기반 주문 생성 API 스코프

## 요청
- 재고가 부족하면 주문 생성을 거절하고 HTTP 409를 반환한다.
- 재고가 충분하면 재고를 차감하고 주문을 생성한다.

## 현재 프로젝트 관찰
- Django 4.2 프로젝트이며 `catalog` 앱만 존재한다.
- 기존 도메인 모델은 `catalog.models.Product(name, price, stock)`뿐이다.
- 주문 모델, 주문 생성 API, API URL은 아직 없다.
- 테스트 파일은 비어 있다.

## 경계
- 한 상품에 대한 주문 생성만 다룬다.
- 요청은 상품 식별자와 주문 수량을 포함한다.
- 성공 시 주문 생성 결과와 차감 후 재고를 외부에서 확인할 수 있어야 한다.
- 재고 부족 시 상품 재고와 주문 데이터는 바뀌지 않아야 한다.
- 인증, 결제, 배송, 장바구니, 다중 상품 주문, 멱등성 키는 이번 범위에서 제외한다.

## 제안 활성 lens
- ddd: 주문 생성 정책과 재고 차감 불변식이 필요하므로 활성.
- api: 새 주문 생성 HTTP 계약과 409 응답 계약이 필요하므로 활성.
- db: 주문 저장 모델과 재고 차감 트랜잭션/마이그레이션이 필요하므로 활성.

## 배치 선택
- 사용자 승인에 따라 기존 `catalog` 영역에 포함한다.
