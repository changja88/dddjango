## 0. 결론 요약 (먼저 공격해야 할 곳)

1. **T3 는 alias 문제의 성격을 바꿨다.** T2 시점 후보는 «basis 필드가 인용한 #N»(배선 근거)이었다. T3 이관으로
   **`discipline-houserules/references/final.md` §0·§1 이 그래프 정본이 되면서**(그 절들에 `graph-owned` 마커가
   박혔다), 538 원장 규칙의 **축자 전사 Work 가 그래프 안에 실재**하게 됐다 — `djr:R-3179 «#486 — 어느 BC 를 열어도
   골격이 그대로 있다»` 꼴. 즉 후보는 이제 «인용»이 아니라 **«동일성»** 이다. 판정 재료가 문면 유추에서 축자
   대조로 바뀌었고, v2 §0.2 의 보수 기준을 그대로 써도 **등재 가능 건수가 3 → 21 로 늘어난다**.
2. **동시에 기존 대장 3건 중 2건이 흔들린다.** `rule#486`→R-0118 은 **취소**(합성 규칙 판명 — v2 가 `#119` 에
   적용한 바로 그 사유가 `#486` 에 그대로 성립한다), `rule#488`→R-0120 은 **재귀속**(정본 Work `R-3181` 로 이전).
   `rule#3`→R-0124 만 무변이다.
3. **번호 공간이 v2 선언과 어긋난다.** 블루프린트 v2 §alias 는 5종(`reg#`·`rule#`·`ddd:결정#`·`slot#`·§앵커)을
   선언했으나 그래프 실측은 **rule(93종) · registry(27종 — 1~27 완비) · 의사결정(7종) · 외부 GitHub 이슈(1종)**
   이고 `slot#N` 은 **번호 인용이 0**이다(«12-slot» 은 산문 어구로만 존재). 그런데 `ontology_structural_check.py`
   의 ⑥″ 는 `^rule#[1-9][0-9]*$` 하나만 통과시킨다 — **선언 5종 ↔ 구현 1종**의 문서-도구 불일치가 미해소다.
4. **«무접두 #N 본문 편입»은 기각(현 처분 유지)한다.** 근거는 감정이 아니라 계수다: 538 규칙 중 그래프에
   **정본 동일성 Work 를 가진 것은 30종(5.6%)**, 라벨 어디에라도 등장하는 것이 93종(17.3%), 블록 본문까지 세어
   177종(32.9%)이다. 나머지 361종은 그래프에 흔적이 없고, tree-revision-spec 을 통째 이관하면 **동결 센서스
   분모(926절·3,235문장)를 재동결**해야 하며 즉시 **30종 재진술 충돌**이 생긴다. 대신 «잔존» 처분에 **조건 3개**를
   붙인다(§5).
5. **자신 없는 곳 3가지**(§7): ⓐ «재진술 ↔ 합성» 구분선이 이 메모의 새 기준인데, `#492` 하나가 그 선 위에 정확히
   걸려 있다 ⓑ `#74` 단독 등재가 검사기 docstring 23개를 한꺼번에 뒤집는데, 그 «대상 0건 가드» 인용이 규범 인용인지
   구현 주석인지의 판정을 문면 1건(`check-naming.py:505`)으로 일반화했다 ⓒ 재귀속(`#488`)이 이미 «실증된 조인»을
   갈아끼우는 행위라 T2-2 §5 의 end-to-end 실증을 다시 돌려야 한다.

## 2. 판정 기준 — v2 기준 + T3 신설 2조

v2 §0.2 기준을 **그대로 승계**한다: *alias 등재 = «#N 의 규범 내용과 Work 의 규범 내용이 같은 사건을
금지·의무화한다» — 주어·양상·술어 일치. 부분 겹침·상위 구간 인용·집행 축 인용은 미등재.* 여기에 T3 재료가
강제한 2조를 더한다.

- **④ 정본 우선(신설)**: 같은 규범을 담지한 Work 가 둘 이상이면 alias 는 **값 소유자 문서의 Work** 를 가리킨다.
  근거 = `rule-owner-map` 머리말 ⓐ «정본(`skills/discipline-houserules/references/final.md`)은 **전 규칙**의 값
  소유자» + 해당 절의 `<!-- graph-owned -->` 마커. → `#488` 의 대상이 R-0120(architecture-ddd 파생 진술) 에서
  R-3181(정본 §0 불릿) 로 **재귀속**되는 근거다.
- **⑤ 재진술 ↔ 합성 구분(신설)**: 한 #N 이 복수 Work 에 걸릴 때 둘을 갈라 처분한다.
  - **재진술** = «같은 사건을 두 번 진술»(한쪽이 스스로 «재인용»이라 밝히거나, 정본 불릿 ↔ 파생 문서 요약 관계).
    → 정본 Work 로 **등재**하되 소급 재진술 패스의 `restates` 연결을 **조건으로 명기**한다.
  - **합성** = «한 번호 안에 서로 다른 두 사건»(원장 한 행이 2문 이상이고 이관이 원자 분리했다).
    → **미등재**. v2 가 `#119`(소유 의무 ↔ 재선언 금지 → R-0075/R-0076)에 내린 처분과 동일 사유. 함수적 alias
    (`aliasText` → 단일 `aliasFor`)가 구조적으로 불가하다.
