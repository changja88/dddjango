# 독립 시안 충실도 평가 요구

이 원본은 평가용으로 만든 화면이며 실제 춘몽 서비스 시안이 아니다. 제공된 HTML/CSS/JS/이미지의 외형과 모든 단계를 독립 Django 앱에 구현한다. 외부 업무 API나 데이터 저장은 없다. 필요한 로컬 UI 상호작용은 포함한다. 원본 외형 변경, 효과 생략, 다른 이미지 사용, 요구 범위 축소는 승인하지 않았다.

대상 viewport는 1440×900과 390×844다. 각 viewport에서 첫 단계 기본 상태, 첫 단계 이름 입력 focus 상태(이름: 하늘), 둘째 단계 밝게 선택 상태, 셋째 단계 검토, 완료 화면을 원본과 구현 모두 확인한다. 총 10개 case다. 이전 버튼은 값을 보존하고 다시 시작은 첫 상태로 초기화한다. 하단 링크는 현재 원본처럼 외부 이동이 없다.

코드 구조와 토큰 이름은 구현 규율에 따라 결정하되 외형은 원본에서 직접 확인한다. 원본 전체 복합 효과와 자식 효과가 적용돼야 한다. 정답 수치나 구현 파일 분해는 이 요구 문서에 재서술하지 않는다.
