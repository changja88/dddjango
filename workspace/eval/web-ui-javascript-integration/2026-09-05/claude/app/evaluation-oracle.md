# UI integration oracle — fixed before runtime generation

Run the same requirements independently through Claude and Codex roles. Record native role/skill load evidence and exact artifact paths/hashes, host mode, and failures/fixes. Keep role orchestration proof separate from installed marketplace or full Coordinator gate proof.

| ID | Observable assertion | Failure control |
|---|---|---|
| I1 | Password reveal/conceal changes only its own input and accessible state | Neighbor must stay masked/value unchanged |
| I2 | Password control works through keyboard | Mouse-only success insufficient |
| I3 | Two image previews show own literal filename and decoded local image | Neighbor preview unchanged; filename markup not interpreted |
| I4 | Reselect/clear releases prior object URL and clears prior success | Track actual create/revokeObjectURL calls, not listener counts |
| I5 | Invalid/failed image has a failure/empty state and no stale prior success | Supply invalid content or force actual image decode failure |
| I6 | HTMX replacement has actual outgoing HTTP request and returned revision marker | dispatchEvent-only processing is not proof |
| I7 | New root and child-replaced UI work after repeated actual swaps | One operation must yield one effect; stale nodes/duplicates fail |
| I8 | Independent child swap leaves retained owner's image and resources valid | Retained preview URL must not be revoked |
| I9 | Removing/replacing resource owner releases that owner's resources only | Retained neighbor stays usable |
| I10 | Native disclosure works with custom feature scripts disabled | No disclosure JS file or handler required |
| I11 | Feature/core scripts have one network load per page, fragments contain no executable scripts | Repeat swaps and inspect network/response HTML |
| I12 | Browser console/pageerrors and Django system check have no introduced errors | Explicitly report omitted/unavailable checks |
| S1 | Required local UI JS is accepted by design/code/audit roles | Blanket JS rejection fails integration |
| S2 | Independent reviewer rejects a proposed JS business-authority decision | Isolated counterexample; no real business implementation needed |
| S3 | Native disclosure is assigned to HTML, without extra feature JS | Necessary JS elsewhere does not justify JS for every feature |
| B1 | Final generated app passes canonical backstop under actual applicable baseline/all mode | Do not relabel new files as legacy or suppress finding IDs |

Tests may use known browser instrumentation for resource accounting and isolated failure injection, but must label injected conditions. Selectors can be derived from the generated design/DOM; behavioral expectations above cannot be weakened after seeing output. Record actual runtime/browser versions and number of runs; one controlled sample per runtime is not statistical proof.
