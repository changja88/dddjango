## 의미적 변종 / backstop-blind 메타

- **치명 의미변종**: **0건**. `[결정PASS ∧ 의미FAIL]` 칸 비었음. 특히 SD-6은 `check-error-centralization` exit0을 *믿지 않고* 에러 경로 전체(operation·5 핸들러·problem 헬퍼·app 계층)를 정독 — status 객체 app 흐름·죽은 핸들러 **없음**(DR-24 Codex C2/C3 의미변종 *부재*).
- **backstop-blind 확인**: 백스톱이 원리상 못 보는 것 = (SD-6) status:int 객체 app 흐름·presentation 수제응답 / (P-β) `application/common/` 외 위치오류. **둘 다 의미 레인서 직접 확인** → 변종 없음.
- **NJ-1 경계(비치명)**: 중앙핸들러가 `django.http.HttpResponse`로 problem+json 반환(`problem.py:71`). §1.2 Q-a상 `JsonResponse`류 = 🟡 경미 후보지만, (a) RFC 9457 `application/problem+json` 미디어타입은 `ninja.responses.Response` 기본 미발행 (b) *중앙 변환점 내부*라 §6.2 carve-out 적용 → **plain leak 아님·NJ-1 PASS 유지**(투명 기록).
