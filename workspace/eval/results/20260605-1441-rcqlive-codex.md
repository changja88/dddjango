## 의미적 변종 / backstop-blind 메타

- **[결정 PASS ∧ 의미 FAIL] 칸 = 없음** — 치명 항목에 의미적 변종 0(DR-24 류 "백스톱 통과하나 의미 위반" 미발생). 13 백스톱 exit0이 *실제로* 준수와 정합(과거 C 트랙 같은 백스톱-맹점 변종 없음).
- **백스톱 맹점 관찰**:
  - **⑬ check-test-config exit0 ↔ Q-6 FAIL**: ⑬은 "pytest 설정이 *있는데* DSM 누락"만 본다. pytest를 **아예 미도입**하면 검사 대상이 없어 exit0 — 즉 ⑬은 *pytest 채택 자체*를 강제하지 못함(설계상 한계, DR-42 기록). Q-6 폴백은 의미 레인 전담.
  - **⑦ check-app-container exit0 ↔ SH-9 FAIL**: ⑦은 등록 앱의 위치(application/)만 본다. 루트 `catalog/` 잔존(shim+vestigial)은 등록앱이 아니라 미발화. 이중 레이아웃은 의미 레인 전담.
  - **mechanism/⑧ exit0 ↔ Q-1 협상**: `_get_urls()` ninja 프레임워크 오버라이드는 DB 메커니즘 백스톱 범위 밖.
