## 의미적 변종 / backstop-blind 메타 (§1.3 — 측정의 주 산출물)

- **`[결정PASS ∧ 의미FAIL]` 칸 = 빈칸** — 의미적 변종 **0건**. 결정 레인(grep·백스톱 15종 exit0·FC 실측)과 의미 레인(블라인드 grader 4명: 공정 3 = 12/12 PASS·적대 1 = 11 PASS+Q-3 WEAK)이 전 치명 차원 일치.
- **형태매칭이 못 보는 함정 4명 공통 반증**: ① 이름위장 빈혈 없음(`Order.place`가 실판정·껍데기 아님) ② status 객체 app 흐름 없음(`Status`는 presentation 전용·app은 bare `Order` 반환) ③ 죽은 도메인 메서드 없음(SD-2 프로덕션 호출 입증) ④ 죽은 중앙핸들러 없음(`test_order_api_problem_details`로 400/422/500 실발화) ⑤ 스코프 발명 없음(멱등성·동시성 코드 0·G1 분리) ⑥ 가짜 테스트 없음(DB 상태·order count·problem type 단언).
- **백스톱이 원리상 못 보는 빈혈(C형)도 의미 레인 통과**: anemic 백스톱 제거됐으나 SD-1/SD-3 빈혈은 의미 레인 1차(4명)+grep(infra CAS `stock__gte=qty` 0)로 *판정 도메인 소유* 확정 — 백스톱 부재가 빈혈 판정 약화 안 함(제거 근거 자체가 "형태매칭 양립불가·reviewer/의미 위임").
- **비치명 잔여흠(라벨 무영향)**: ⓐ `infra/repository/order_repository.py:11` `with_identity`가 도메인 `_clock()` created_at을 DB `auto_now_add`로 덮음(도메인 시계 폐기·도메인 오류 아님·미세 중복) ⓑ `_is_transient_operational_error`(api.py:65-68) 메시지 문자열 매칭(부서지기 쉬우나 503은 동시성 G1 영역·task 외) ⓒ 루트 빈 `catalog/migrations/` 잔재.
