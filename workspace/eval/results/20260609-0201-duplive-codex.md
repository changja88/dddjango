# 의미적 변종 / backstop-blind 메타

- **의미적 변종 [결정PASS ∧ 의미FAIL] = 0건** (적대 grader 확인): status:int plain 객체 app/domain 흐름 0 · operation raw 응답 0 · 죽은 중앙핸들러 0 · ACL 밖 누수 0.
- **backstop-blind**: ⑰ `check-duplicate-app`는 migrations-only 루트 잔재를 **원리상 면제**(G2 full-app-package 불충족) — 이번 완전이주는 정당 exit0. `check-app-container`(⑦)도 루트 apps.py 부재라 exit0(정상).
- **NJ-7 의미적 한계(라벨 무영향)**: catch-all은 등록·되던지기 0이나, ninja **파싱단계** `HttpError(400)`는 `@api.exception_handler(Exception)` *밖*에서 발생 → problem+json 단일변환점을 원리상 우회(EP-1 흠의 뿌리·NJ-7 정적 PASS와 별개).
