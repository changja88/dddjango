## 의미적 변종 / backstop-blind 메타

- **🔴 SH-1·4 = [결정 PASS ∧ 의미 FAIL] 의미적 변종 → 치명 FAIL**(§2.2): `check-app-container.py` **exit0**(catalog 루트 평면 판정적재를 *못 봄*) — 백스톱은 "신규 앱 루트 생성"은 잡으나 **기존 루트 앱(`catalog/`)에 판정·도메인서비스 적재**는 미포착. 의미 레인(마스크 C)이 전담해 FAIL 확정. **→ 백스톱 갭(DR-26 `check-app-container` 사각): 기존 루트 데이터소스 앱의 *판정 적재 후 위치 미이주*를 결정 레인이 못 잡음.**
- SD-3: 결정 레인 `stock__gte=quantity` 신호(🟡)이나 도메인 메서드 존재(B형)라 의미 레인 PASS — C4 백스톱 ⑪ 설계대로 비치명.

## 조정자 노트 (결론)

1. **catalog 위치 = P4③ 재현**: 같은 태스크에서 Codex는 catalog **평면 유지 + `domain_layer`/`published_service` 적재**(판정 소유), Claude(같은 라운드 진행 중)는 G1 게이트에서 **4계층 이주** 선택. **런타임 간 catalog 이주 비결정**(DR-24·c4live 계보). 표준은 "touched+판정적재 → 이주 의무"라 Codex 선택이 **SH-1·4 FAIL** — *underdetermined 아님*(메모리 catalog-container-regression "touched 데이터소스는 위치 이주 의무" 적용).
2. **테마 A 처방은 라이브 실현**: maj1(`handle_database_error` 503/500·sqlstate 40001/40P01/55P03·메시지·단위테스트 3종) + maj2(깨진본문 400 `application/problem+json`) + D2(status 표 503 retryable 열거) = **DR-44/45가 노린 ACL 인프라-예외 누수 처방을 Codex가 구현**. presentation 단일 변환점(`error_handler.py`)·ACL은 도메인 예외만 번역·인프라 예외는 경계가 매핑.
3. **그러나 maj1 불완전 + min1 미반영(동적 재현)**: Exception catch-all 핸들러 부재 → `OverflowError`(거대 product_id, `stock.py:16`) 같은 **비-DatabaseError가 500 `text/plain`으로 누출**(problem+json 아님). min1 처방(§5.1 수치 입력 상한)을 schema가 반영 안 함(`Field(gt=0)` 하한만).
4. **Q-6 = DR-42/45 재현**: Codex가 pytest 부트스트랩을 또 안 함(Django `TestCase`·기본 디스커버리 0). 자기보고 "manage.py test 17 OK"는 경로 명시 시에만 성립 — 자기보고 불신 원칙이 적중.
5. **N=1·우열 아님**: 치명 FAIL 레인이 런마다 갈린다(P4③). 이 라운드는 "테마 A+B 처방이 라이브서 실현되나"의 방향타 — maj1·maj2는 ✅ 실현, catalog 위치·min1·Q-6은 별개 회귀.
