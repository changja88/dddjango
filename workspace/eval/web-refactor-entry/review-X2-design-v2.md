### M3. `--subst-check` 폴더 쌍이 파일 하나의 이동에서 영역 단위 거짓 쌍을 만들어 거짓 green 을 낸다 (§7-2 :248)

- **실험** [실측 — 합성 `fp/` · `subst_proto.py`]
  - 이동은 `web/a/x/f.py → web/a/z/f.py` · `web/a/x/g.py → web/b/x/g.py` 둘이다.
  - 공통 꼬리를 떼어 폴더 쌍을 뽑으면 `a/x → a/z` 와 **`a → b`**(`web.a → web.b`)가 나온다.
  - 테스트 첫 줄 `from web.a.q import V` 를 `from web.b.q import V` 로 바꿨다. `web/a/q.py` 는 옮기지 않았고, 테스트가 다른 모듈을 보게 되는 변경이다. 그런데 결과는 **exit 0(green)** 이다.
- **왜 중요한가**
  - 영역 사이 이동(undecidable-web §4 «영역 귀속»이 렌즈에 있다 — M 항목으로 나온다)에서 흔한 실수는 테스트 파일에 `sed s/web.<a>/web.<b>/g` 를 넓게 거는 것이다. 이 실수가 치환 확인을 그대로 통과한다.
  - 참조 완전성도 옛 꼬리가 사라져 exit 1 이다. 기계 확인 둘이 함께 뚫린다(B1 의 ⑤ 가 없으면 테스트도 돌지 않는다).
- **고칠 말**: «폴더 쌍은 기준 트리의 옛 폴더 아래 파일이 **전부** 같은 접두 변환으로 개명됐고 대상 트리에 옛 폴더가 없을 때만 만든다. 그 밖의 파일 쌍은 파일 꼬리·점 경로 쌍만 쓴다.» W6-T8 에 «파일 하나 이동 → 폴더 쌍 없음 · 넓은 sed → red»를 더한다.
