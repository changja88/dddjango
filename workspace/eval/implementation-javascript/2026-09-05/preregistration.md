# implementation-javascript 평가 사전 기준

2026-09-05. 스킬 집필 전 기록. 생성 코드는 임시 디렉터리에서만 실행한다.
목적은 스킬의 구현·감수 효용과 범위 판별 확인이다. 플러그인 전체 발화나 실제 앱 인수 증명은 아니다.

## 비교 과제

같은 파일 미리보기 요구와 DOM 계약을 baseline/with-skill에 제공한다. 별도 에이전트는 서로의 코드·평가 결과를 보지 않는다. 스킬 적용군만 신규 SKILL.md 및 필요한 reference를 읽는다. 수정된 동일 에이전트의 결과를 독립 재평가로 부르지 않는다.

## 실행 오라클

| ID | 현재 요구·불변식 | 관찰할 실패 |
|---|---|---|
| B1 | 첫 로드 뒤 선택 이미지·파일명 표시, clear 동작 | 이벤트 연결 누락·입력 미정리 |
| B2 | 2개 이상의 UI는 독립 | 전역 selector·전역 선택 상태가 다른 UI 변경 |
| B3 | 같은 루트 재처리에도 동작·자원 생성 중복 없음 | 반복 초기화 시 이벤트 중복 |
| B4 | HTMX innerHTML로 추가한 UI 동작 | 초기 DOM만 스캔 |
| B5 | HTMX outerHTML로 교체한 root 자체도 동작 | descendants-only 검색으로 전달 root 누락 |
| B6 | 교체·삭제 전에 이전 UI의 blob URL 수명 종료 | 참조 해제 누락 |
| B7 | clear·재선택·비이미지 선택에서 이전 URL 정리 | 오래 열린 UI의 자원 축적 |
| B8 | 파일명은 문자 그대로 표시 | HTML 실행·마크업 삽입 |
| B9 | HTMX 실제 HTTP 요청과 교체에서 검증 | 이벤트 수동 발사만으로 통합 통과 주장 |

B3의 반복 load 이벤트는 초기화 멱등성 확인용이며 B9 실제 교체를 대체하지 않는다.
자원 계측은 createObjectURL/revokeObjectURL을 감싸되 실제 원본 API를 호출한다. 브라우저 의미를 대체하는 mock DOM은 쓰지 않는다.

## 별도 사례

- JS 불필요: 기본 details/summary로 충분한 disclosure.
- 경계: 서버 권한·금액 판정, 승인되지 않은 업무 API 직접 호출.
- 별도 UI: Promise가 늦게 끝나는 복사 완료 안내. 제거된 root 및 이전 작업 결과를 새 UI에 적용하지 않아야 한다.
- 리뷰: 정상 최소 구현을 불필요한 프레임워크 부재로 반송하지 않고, 실제 초기화·정리·안전한 DOM 오류를 근거와 함께 판정해야 한다.

## 판정의 한계

실패가 없으면 개선을 입증했다고 쓰지 않는다. 단일 모델·제한된 사례 평가이며, DOM 사례나 기능 이름을 스킬의 보편 규칙으로 복제하지 않는다. 실행한 조건·누락·발견·수정·재실행을 최종 report.md에 구분한다.

## 탐색 사례 E1 추가 — 기본 평가 이후, 스킬 집필 이전

기준선은 B1–B9를 통과했다. 아래는 사전 등록 점수에 합치지 않는 추가 탐색이다.
root·input·image·output을 유지한 채, 같은 root 안의 독립 안내 조각만 HTMX로 삭제한다.
파일 선택과 그 미리보기는 그대로 남아야 한다. 정리 이벤트가 부모 기능 전체의 파괴와 같다는 가정을 검사한다.
이 탐색으로 얻은 지침을 스킬에 반영한다면 E1의 적용군 통과는 해당 수정 확인이지 독립 일반화 증거가 아니다.
