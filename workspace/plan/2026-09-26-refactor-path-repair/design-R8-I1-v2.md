## 1. 원칙

- **완료 기준 하나** — 슬라이스 0 에서 `M<n>` 의 «해소»는 원 행(verdict 행 · 원 리뷰어 행 · 병합 행)의 위반 요지가 원 규칙의 처방대로 사라진 것이다. G2 residual 잔존 확인과 같은 기준이다(리뷰 보정 4 — verdict 처방 기준과 원 행 요지 기준의 이중성을 닫는다).
- **대체 형태 금지** — 원 규칙의 처방이 아닌 다른 개선(파생 프로퍼티 대신 생성 시 검증 · 인수 객체 대신 키워드 전용 · 전제 검사 대신 docstring 단정)은 해소가 아니고 슬라이스 0 에 넣지 않는다. 근거: G0 ⓐ 가 승인한 것은 «그 위반의 정리»다 · residual 이 대체 형태를 해소로 세지 않는다(R8-R t05 리뷰어 문언) · 플러그인 자신의 정의에서 답이 나오므로 묻지 않는다.
- **판정 단위 = 요지** — 요지 판정은 `해소 | 불가` 둘이다. 항목 판정은 파생한다: 요지 전부 해소 = 해소 · 일부 = 부분 · 하나도 없음 = 불가.
- **자기 증명 차단(리뷰 M2)** — 불가·부분 주장도 리뷰어가 본다(과대 제외 · 요지 과소 기술). 리뷰어 이의가 우선이다.

## 4. 재상정 결정 줄 — 닫힌 어휘와 요지 축소 정형

- **결정 칸 첫 낱말 닫힌 어휘(리뷰 M3)**: `ⓐ 재상정` 절의 결정 줄 첫 낱말은 `별도`(별도 요청) · `선행`(선행 별도 요청(정지)) · `ⓑ` · `플러그인`(플러그인 결함) · `작업`(작업 중단) · `요지`(요지 축소) 여섯뿐이다. 밖이면 `_scope` 가 ToolError(exit 1) — 표기가 흔들려 키가 조용히 빠지는 fail-open 을 막는다. 빈 자리표시(`결정 = · …`)는 종전대로 결정이 아니다. 끝난 R8-R 폴더의 재상정 토큰(`별도`·`ⓑ`·`플러그인`)은 모두 어휘 안이다(§9 재생).
- **요지 축소 정형**(항목마다 한 줄):

```
- M<n> · 결정 = 요지 축소 · 남긴 요지 = #<k>[·#<k>…] · 뺀 요지 = #<j>[·#<j>…] → <처분> · 남김 근거 = 해소 판정 표 | 사용자 선택 · 출처 = <Phase 0 결정 출처 정형>
```

  - 요지 번호 = 명세 판정 표의 `요지#`. `<처분>` 첫 낱말은 `별도`·`선행`·`ⓑ`·`플러그인`·`작업` 가운데 하나(요지 아님).
  - `남김 근거 = 해소 판정 표`: G1 에서 합친 부분 항목 — 남김은 설계 판정이다. 출처는 뺀 요지 처분에만 걸리고 «사용자 결정» 표기는 그 처분에만(리뷰 m1 · Phase 0 `:84` «사용자 결정 표기는 본인 직접·사용자 원문 출처에만»).
  - `남김 근거 = 사용자 선택`: Phase 2 STOP 에서 사용자가 일부만 빼기를 고른 경우(M8 형) — 결정 전체가 사용자 원문이다.
  - Phase 2 STOP 은 표에 없던 요지 경계를 만든다 → 사용자 답을 먼저 STOP 기록에 추기하고, architect G1′ 로 표의 요지를 나눈 뒤 그 번호로 결정 줄을 쓴다.
  - 머리의 병합 표기 `M8(+M47)` 는 허용한다(괄호 안은 병합 항목). 괄호 밖 M 키는 정확히 하나.
- `_scope` 처리: 재상정 절에서 `요지` 줄은 빼지 않고 축소 목록(마지막 줄이 이긴다)에 싣는다. 같은 항목에 요지 축소 줄과 전체 제외 줄이 함께 있으면 전체 제외가 이긴다(G2 잔존 STOP 의 철회 · 수정 요청 전체 제외).

### 5-2. `_scope` · `residual`

- `_scope(folder)` → `(audit 시각, adopted, removed, reductions)` — 닫힌 어휘 ToolError · 요지 축소 정형 ToolError(항목 하나 · 남긴/뺀 요지 번호 · 뺀 요지 처분 어휘 · 남김 근거 값 · 번호 겹침).
- `residual`: `items = adopted − removed` 는 그대로(요지 축소 항목은 남는다 — F1 봉쇄). 요지 축소 항목의 묶음에 `- 요지 축소(재상정 <시각>): 남긴 요지 #k «…» — 이 요지만 확인한다 · 뺀 요지 #j «…» → <처분>` 을 싣고(요지 원문은 명세 판정 표 — 번호가 표에 없으면 ToolError), 그런 항목이 있는 묶음 머리에 «요지 축소 항목은 남긴 요지만 본다 — 뺀 요지는 재상정 처분 몫이다» 1줄. 요약에 `요지 축소 k`(k>0 일 때만 — 기존 출력 무변).
- 결정적 바닥(항목 파일 전부 무변 → 잔존)은 요지 축소 항목에도 같다(fail-closed 쪽).
