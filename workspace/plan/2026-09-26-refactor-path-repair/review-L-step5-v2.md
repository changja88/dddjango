## Blocker

### L-B1 슬라이스 0 에서 빠지는 출구의 기계 검사가 과소·과잉을 동시에 낸다 (K-B1 잔여)

- **위치**: v2 §3-1 `check-verdict` 행 · §4-2 · §4-3 · §4-4 · §5 · §7 끝 줄
- **근거**
  1. **결속이 절 단위다** [실측].
     - rulepack 은 블록 텍스트를 싣지 않는다(q4 머리 «금지: `djr:text` 는 뽑지 않는다» · 동결 개정 8).
     - 한 블록이 여러 규범을 진술한다. 예: ninja `s010-2.3/b1` = R-0696·R-0697·R-0698·R-0699·R-3403(`implementation-django-ninja-final.ttl:2698`).
     - 절이 크다: DR s007 216 규범 · ninja §6.2 89 · ninja §2.3 40.
     - `check` 가 붙이는 것은 «그 절의 R-ID 목록»뿐이다. «이 인용이 이 R-ID 의 문장인가»는 검사되지 않는다.
  2. **«요건 불충족» 가지는 무력하다**.
     - 행에 위반 R-ID 가 하나로 고정되지 않는다(절 목록뿐).
     - 그래서 «같은 절의 아무 의무·금지 R-ID + 그 절의 아무 부분 문자열»이면 통과한다. 어떤 항목이든 뺄 수 있다 [실측 구조 · 영향 추정].
  3. **탈락은 검사가 없다** [실측 문면].
     - `check-verdict` 조건 목록(§3-1)에 탈락이 없다.
     - G0 는 건수만 보인다(§5). G2 재표시는 «제외·별도 요청»뿐이다(§7).
     - 뺄 항목을 «탈락(오탐)»으로 적으면 §4-3 전체를 비켜 간다.
  4. **별도 요청 근거는 «실재»만 본다**(§4-4).
     - «마이그레이션이 필요한 모델 필드 `파일:행`»은 아무 모델 필드 행이면 통과한다. «테스트 참조»는 아무 import 행이면 통과한다.
     - 별도 요청은 질문 없이 표시만 된다. 결정적 검사 없이 architect 가 항목을 뺀다.
  5. **병합 → `M<k>` 의 대상 판정을 보지 않는다**. 제외·별도 요청된 `M<k>` 로 병합하면 사슬로 빠진다.
  6. **kind 규칙이 과잉이다** [실측].
     - 5B 표본 제외 5건 중 #15 의 근거 R-1395 «우연히 값이 같은 다른 지식의 통합 금지»는 **Prohibition** 이다(`discipline-cleancode-final.ttl:221`). v2 규칙으로는 red 다.
     - 정당한 «반대 방향 금지» 제외가 막힌다. architect 는 사용자 판단(자율 실행이면 정지)이나 무검사 탈락으로 돌린다.
  7. **kind 규칙이 과소다** [실측].
     - Override 35건 중 R-1411 «심볼 치환의 판정 소유 면책 금지» · R-1489 ««없다…»는 예외가 아니라 답»은 의무를 되살리는 규범이다. 그런데 kind=Override 라 제외 근거로 통과한다. 새 리팩토링 Override 자신도 통과한다.
     - `djr:overrides` 는 어휘(`djr.ttl:165`)에만 있고 규범 사용이 0이다. «Override 대상이면 불가» 검사는 새 규범 셋만 덮는다.
- **영향**: 결정 1-b «항목을 빼려면 규칙 문구를 근거로»가 기계로 보장되지 않는다. 자율 실행에서는 G0 가 위임되므로(현장 발주자 답 25건 — `diag-A-field-evidence.md:64`), 빠진 항목은 G2 배너 목록으로만 드러난다.
- **권고(최소)**
  - `check-verdict` 를 빠지는 출구 전부(제외·탈락·별도 요청·병합)에 건다.
  - 탈락과 «요건 불충족» 제외를 한 형식으로 합친다: «위반으로 인용된 그 블록의 요건 문구 인용».
  - 결속은 블록 단위로 한다. rulepack 에 블록별 정규화 해시(본문 아님 — 개정 8 무접촉)를 투영해 md 문단과 맞춘다. 한 블록에 kind 가 섞이면 사람 검토 표시.
  - 제외 kind 는 {Permission, Exception} + 리뷰어가 «반대 방향 규칙» 열에 적은 규칙(kind 무관 — R-1395 형)으로 한다. Override 는 `overrides` 대상이 위반 규칙일 때만.
  - 별도 요청 근거는 유형별 구조 검사: 모델 필드 = ORM 모델 파일 ∧ 항목 `파일:행` 과 겹침 · 타 BC = BC 밖 경로 · 테스트 참조 = 그 행에 항목 정의 이름 문자열.
  - 병합 대상 = 채택 `M<k>` 또는 registry `C<n>`.
  - G2 재표시에 탈락 목록을 더한다.
