- «이 실행의 편집인가»의 보증은 둘로 나뉜다.
  - 병합은 발주자가 보증한다(§8 7-1).

  - 기록이 없으면 엄격한 쪽으로 떨어진다.

**비테스트는 순변화로 본다.**

**테스트는 슬라이스 0 대조 구간으로 본다.**
- 한 파일을 슬라이스 0 과 기능 슬라이스가 함께 바꿀 수 있어서, 슬라이스 0 몫만 떼어 본다.

**재료가 없으면 엄격한 쪽이다.**

- `slices[0]` 은 이름과 무관하게 슬라이스 0 이다(`C:208` · S16k).
