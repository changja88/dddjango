## E. 특기 관측 (스팩 공백·G0 인터뷰 재료 — 명세 본문 아님)

- **재시도 비대칭**: 수정·삭제만 transient 1회 재시도, 생성은 무재시도(V1 축자).
  의도인지 공백인지 인터뷰 대상.
- **transient 판정 집합 3원화**: 응용 재시도(framework 판정기: SQLSTATE 3종+sqlite
  메시지) / admin 503 판정(BC 로컬: SQLSTATE 3종만) / 중앙 API 503 판정(메시지
  휴리스틱+SQLSTATE 2종 — `55P03` 은 메시지에 "locked" 가 없으면 500 이 될 수 있다).
  V1 실물의 불일치 — 재구현에서 단일화할지 인터뷰 대상.
- **이름 중복의 운영자 경험**: 유일 제약 위반이 전용 안내 없이 서버 오류로 나온다
  (§4 축자) — 수용인지 개선인지 인터뷰 대상.
- **admin 수정 폼의 이중 검증**: 폼 clean 에서 도메인 검증을 선실행(수정 화면 한정 —
  생성 화면은 저장 시점 검증만). 표면 일관성 인터뷰 대상.
