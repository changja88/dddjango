2. **Claude Code 서브에이전트 · 맥락**: 서브에이전트를 이어 깨울 때(SendMessage · resume) 대화 전체가 유지되고 캐시가 이어지나 · 새로 부를 때 처음 싣는 것(시스템 프롬프트 · CLAUDE.md · 스킬 설명 · 도구 정의)과 그 크기 · 서브에이전트 자동 compact 조건 · Anthropic 이 공식으로 낸 «긴 맥락에서 품질 저하(context rot 등)» · «긴 작업은 새 맥락으로 나눠라» 류 지침이 있나(엔지니어링 블로그 포함).
3. **Codex 하위 에이전트**: 하위 에이전트를 띄우는 도구의 옵션(`fork_turns` 등)의 정확한 뜻과 기본값 · 무엇을 물려받나 · 동시 실행 상한 설정 이름과 기본값 · `wait_agent` 동작 · 대화 상속이 OpenAI 프롬프트 캐시(접두 캐시)와 지연에 주는 영향 · Codex 자동 compact 조건. **가능하면 `openai/codex` 소스(0.159.x 태그 또는 가장 가까운 커밋)에서 확인**한다.
