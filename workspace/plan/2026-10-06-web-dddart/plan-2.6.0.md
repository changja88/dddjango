## 바뀌는 동작
- 새로 짓는 지속 셸: 탭 왕복 · ‹뒤로›·‹앞으로› 뒤 화면이 떠날 때 그대로(서버 요청 0) · 누르자마자 고른 탭 · 알림은 화면을 넘어 제 시간까지 · 새 화면 제목 읽기 알림 · 동작 뒤 같은 출처 셸 화면 이동도 셸 안(다른 탭 쓰던 글 남음). 새로고침은 주소대로 새로.
- 이미 지은 지속 셸(2.4.0 ~ 2.5.x): 다음 기능 요청의 G1 이 «지속 셸 판 올림»을 묻는다 — 기능 JS 의 `pushState` 층은 H2 를 지키면 그대로 · 보관 중 타이머 · 요청 · 연결은 P12 · 띄우는 알림은 P13 처분이 슬라이스 할 일이다. 리팩토링 · 수정 실행은 옛 판을 그대로 받는다.
- 브라우저 저장소 두 칸: `localStorage["root.who"]`(신원 해시) · `sessionStorage["root.tabs"]`(이 브라우저 탭의 탭 마지막 주소 — 같은 신원 · 같은 셸에서만 · 신원 표지가 없는 호스트는 쓰지 않음). 화면 내용은 저장하지 않는다(`historyCacheSize` 0 그대로).
- SH5: 순서 · 선택자 차례 · 뜻 없는 공백 · 주석만 바뀐 기존 규칙은 세우지 않는다. 값을 바꾼 한 줄 규칙 · 하나 더 쓴 같은 선택자 · 문자열 안 글자가 바뀐 규칙 · 쌍점 앞 / `!` 뒤 공백만 바꾼 규칙은 그대로 잰다. 여러 줄 규칙에서 선언 줄만 바뀐 경우는 2.5.2 처럼 재지 않는다. 기준점에서 주석으로 꺼 둔 load 를 켜면 새로 실린 CSS 로 전수한다.
- 시험 실행의 `--basetemp` 는 기록 폴더 밖(예외는 G2 «완성 화면 그림»의 `captures/tmp` 하나 — Coordinator 가 PNG 를 옮긴 뒤 지운다).

## 한계
- 결과 7(탭별 ‹뒤로›) 없음 — 사용자 결정. 결과 4 일부 — 재탭 ① 뒤 ‹뒤로›는 중첩 화면.
- 보관은 그 문서 기억 안뿐이다 — 새로고침 · 주소로 다시 열기 · 문서 이동(셸 아닌 화면 · 서버 오류 · 배포 뒤 첫 서버 이동) · 보관 상한 30 을 넘긴 오래된 화면은 서버가 다시 그린다(맨 위). bfcache 로 되살린 문서는 보관 화면만 버린다.
- 보관 중 멈춤은 htmx 요청 · 폴링만 저절로다 — 기능 JS 는 P12 를 지켜야 멈춘다. P12 를 어긴 보관 화면의 늦은 `pushState` 는 보이는 화면의 주소 · 탭 마지막 위치로 남을 수 있다(경로를 바꾸는 기능 층 `pushState` 를 살리는 대가). 다른 경로의 `replaceState` 는 화면 주소로 받지 않는다.
- 떠나기 직전 시작한 동작의 공유 갱신은 다른 화면에 오지 않는다(2.4.0 과 같은 끊음 · 그 화면은 돌아올 때 서버에서 새로). GET 아닌 `from:body` 구독은 놓친 갱신을 다시 받지 않는다.
- 계정 경계: 다른 창의 로그아웃 · 로그인이 셸 아닌 화면에서 끝나면 이 창은 다음 서버 화면까지 모른다. 서명 쿠키 세션 · 세션 인증 아닌 백엔드는 계정 지킴이 꺼진다(탭 마지막 위치도 쓰지 않음). 다른 창이 다른 신원으로 셸 화면을 받으면 이 창을 새로 연다(지금 화면 쓰던 글도 사라짐 · 같은 계정 다시 로그인 포함).
- WebKit 에서 «동작 뒤 같은 출처 이동»이 문서 이동으로 간 것이 설계 측정에서 한 번 관측됐다(원인 미확정 — 그때는 주소 · 본문 · 탭은 맞고 보관 화면만 사라짐 = 2.5.2 와 같은 결과).
- 글자 아닌(대상 지정) `HX-Location` 은 셸을 깰 수 있다 — 규칙 «BC 는 `HX-Location` 을 쓰지 않는다».
- iframe 다시 읽힘 · popover 닫힘 · 소리 · 영상은 멈춘 채 돌아옴. 안드로이드 Chrome 시스템 ‹뒤로› · iPhone 가장자리 쓸기는 실기기로 확인하지 않았다.
- 표준 글이 2.4.0 의 약 2.6 배로 커져 감수 «표준 글과 같음» 비교 대상이 커졌다.
- SH5: `"/*"` 문자열이 있는 줄 뒤 같은 줄의 새 갈래는 `mask_css` 가 주석으로 가려 못 본다(2.5.2 부터 · 범위 밖). 포매터가 바꾸는 쌍점 앞 · `!` 뒤 공백은 2.5.2 처럼 기존 규칙을 다시 센다.
