# dddjango-web 2.8.0 — 쓸모없는 시험 막기 (시험 입장 표)

## 문제
- web 에는 영구 시험 입장 심사와 중복 판정이 없었다. 설계자는 시험 규율(discipline-test)을 로드하지 않았고, 명세 쓰기 전 조사에 «기존 시험»이 없었다.
- 규칙이 시험을 만들었다:
  - `SCREEN_PROBES` + `render_smoke_test.py` 필수 산출(쓰는 검사 · 도구 0)
  - «행위 항목마다 1개 이상»
  - 순서 단언의 양끝 echo
  - 정확 개수 단언이 화면 · 층마다 같은 목록으로 번짐(«thick domain 두텁게»가 층마다 같은 경계 표를 되풀이시킴)
- discipline-test §4 금지가 있어도 명세가 시험 방법으로 적거나 G2 시각 보정을 영구 시험으로 남기면 통과했다. 감수는 «필요 없음 · 겹침»을 보지 않았다.
- 목록 · 반복 슬롯이 BC 마다 사본(VM 목록 함수 · 표시 필터 · 템플릿)인 호스트에서는 «한 곳에서만 단언»이 안전망을 지운다 — 기준은 «같은 코드»여야 한다.
- 근거: web 실행 표본의 시험 조사 두 갈래(분석 둘이 일치) — 운영자 작업 기록.

## 고침(구현 검토 · A/B 뒤)
- **고칠 기존 단언이 비자격 꼴이면 걷는다**: 이번 변경으로 기존 시험을 고쳐야 할 때 그 단언이 §4 꼴이면 고쳐 살리지 않고 `update` 행 걷음 칸(근거 §4 항목)으로 걷는다 — 함수째 · 파일째 · 그 단언이 어떤 행위의 유일한 단언이면 갈음 행을 먼저 둔다. Phase 1 ⑤ · 감수 §8 이 본다.
- **시각 행위는 `G2 화면 확인`**(미디어와 같은 꼴 · 표 밖 · G2 배너 목록): 값으로 단언하면 §4 시각 스타일이 되는 것만. 가려짐 · 잘림 · 눌림과 상태 · 분류가 정하는 표지(선택 · 비활성 · 분류 클래스 · aria)는 시험 행이 맡는다.
- **준비 · 호출 맞춤**: 단언과 넘기는 값이 그대로이고 부르는 꼴만 바뀐 고침은 행 없이 통과(선택자 등 보는 대상을 바꾸면 단언 바꿈 · §4 꼴 함수는 맞춤으로 살리지 않음).
- **비자격 단언의 반송 갈래**: 승인 `add` 행이 시켰으면 그 행 → `reject`(그 시험 지움은 약화 아님) · `update` 행이 시켰으면 그 단언만 빼고 `update` 그대로(할 일이 안 남으면 `reject`) · 표 밖이면 coder 반송.
- **`coder 행` 갈래**: 감수는 명세에 남은 앞 요청 표를 쓰지 않는다 · 설계 반송 G1′ 때 `표`로 한 번 바꾸고 coder 행을 표로 옮긴 뒤 `test-entry-coder.md` 를 비워 커밋(재개 때 비움부터) · `test-entry-coder.md` 는 Phase 2 진입 때 빈 파일.
- **렌즈 범위 · 거꾸로 대조**: 입장 대조는 기능 슬라이스 커밋의 시험 변경만(슬라이스 0 · 0T · 이동 · 승인 병합 몫 밖 · 리팩토링 모드 밖) · `표` 갈래 G2 · 수정 모드 감수는 표 `add` · `update` 행마다 기록에 시험 변경이 있는지도 본다(시험 변경 0 이면 «시험 변경 0» 줄) · 슬라이스 커밋 목록을 늘 싣는다.
- **행마다 슬라이스 하나**: 조정자가 슬라이스 도출 뒤 표 행을 슬라이스에 배정해 coder 입력에 싣는다(칸이 층이면 대상 파일이 든 슬라이스 · 못 정하면 그 층 마지막 · 축퇴면 하나).
- **근거 노드 없음 = 설계 반송**: 수집 0 · `not found` 는 근거 id 문제 — 같은 입력으로 다시 부르지 않는다. 근거는 슬라이스 0 · 테스트 이동 뒤 경로로 적고 Phase 1 ① 이 있음을 본다. G2 배너 «근거 노드 통과 p/k».

## 한계
- 새 기계 검사기는 없다(measure-first) — 표 꼴만 조정자가 보고, 뜻은 Phase 1 · 감수가 본다.
- 이미 있는 `render_smoke_test.py` · `SCREEN_PROBES` 와 지금 실행이 손대지 않는 기존 시험은 일괄 정리하지 않는다(기능 슬라이스가 고칠 때만 입장 표로).
- dddart 는 그대로다(web 효과를 잰 뒤 따로). core 의 «기존 시험 고칠 때 다시 묻기»는 다음 판.
- 호스트 쪽 메뉴 사본 통합(제품 리팩토링)은 별도 요청이다.
- 빠른 길(트리비얼 — 새 파일 0 + 문구 · 토큰 값 · 아이콘)은 시험 입장 표 밖이다 — 새 시험은 쓰지 않지만 중복 단언도 걷지 않는다(걷음은 정식 실행이 그 시험을 고칠 때).
- Codex 실행 확인은 하지 않았다(글만 맞춤).
- 설계는 2판 + 3판(바뀐 것) + 3.1 운영자 결정, 적대 설계 검토 세 바퀴(차단 9 → 5 → 3)를 거쳤다. 구현은 적대 검토 세 바퀴(차단 4 → 1 → 1)와 고침 4차를 거쳤다 — 운영자 작업 기록.
