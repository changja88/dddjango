# dddjango-web 2.9.2 — 리팩토링 입구의 리뷰어 표 읽기(F4-212 의 web 짝)

상태: 배포 끝(2026-11-26 01시 53분 · 태그 `dddjango-web--v2.9.2` · 고침 4321b555 · 82a839d1 · release 5df9a3fc · 봉인 4454794a · 64350d12). 함께 나간 판: dddjango 2.46.0(`workspace/plan/2026-11-25-refactor-run-repair/plan-2.46.0.md`).

## 문제

- `refactor_audit` 의 `residual --finalize` · R2 `check` 가 `|` 로 시작하는 줄만 읽었다. 묶음 머리와 리뷰어 지시는 `M<n> | 판정 | 근거` 꼴(앞 `|` 없음)을 시켜, 그대로 적은 답이 전부 «판단 불가» 로 세이거나 R2 가 소리 없이 0행이 되었다.

## 고침

- 앞뒤 `|` 없는 행(`M<n> | …` · 번호 행)도 읽는다 — 잔존 결과 · 단위 점검(R2).
- `답 없음`(결과 파일 없음 · 읽은 항목 행 0 · 그 항목 행 없음)을 `판단 불가` 와 따로 세고, residual 시각마다 한 번 그 렌즈 리뷰어에게 묶음 머리의 표 꼴로 다시 받는다(같은 시각 · 슬라이스 0 재개봉 아님).
- 못 읽은 번호 행 · 코드 상자 안에만 있는 번호 행은 0행으로 넘기지 않고 멈춘다(«코드 상자 안에 있는 표는 읽지 않는다»).
- 리뷰어 글 다섯: 산출 · 잔존 확인 표를 앞뒤 `|` · 코드 상자 없이. 커맨드 G2 문단: `답 없음` 처리.
