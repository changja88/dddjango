## 본뜬 것 — 서버 registry_gate 의 «승인 머지 목록 · provenance 차분»
지적 하나(경로 p)마다 **W(p) ∧ F1(p) ∧ L** 을 증명한 것만 종료 코드에서 빼고 «승인 유입» 절로 보고한다(지우지 않는다).
- W: 작업 트리의 p 가 HEAD 와 같다(미추적 · 개명 포함 · 조회 실패는 «깨끗»으로 안 읽음).
- F1: ∃승인 병합 M: blob(M^1:p) ≠ blob(M:p) = blob(M^2:p) = blob(HEAD:p) — 병합으로 그대로 들어와 레인이 안 바꾼 파일(충돌 해소분 · 병합에서 버린 파일 · 레인이 먼저 같은 내용으로 가진 파일은 탈락).
- L: M^1 · M^2 를 `git archive` 스냅숏(`.dddjango-web` · `.dddjango` 를 뺀 최상위 항목만)으로 풀어 러너를 따로 띄운 프로세스(`sys.executable -B` · `--only st,md,im,nm,tg,pj,pu`)로 전역 실행해, 같은 지적 키(검사 ID · 경로 · `:N` · 위반 문장)가 M^2 에만 있음을 증명. 측정 무효(스냅숏 실패 · exit · 출력 판독 불가 · 두 부모의 Python 파싱 실패 경로 집합이 다름 · 부모 트리에 심볼릭 링크)면 그 병합에서만 증명 기회를 잃는다(∃M).
- 승인 목록 = 산출물 폴더의 `approved-merges.txt`(발주자 소유 · 치환 확인 · WV10 이 이미 쓰는 것). 기준은 HEAD 첫 부모 사슬 위여야 한다.

- 남긴 blocker 아래 `↳ 이 레인 몫으로 남김: <사유>`(가르기를 시도한 실행에서만) · `== 승인 유입(발주자 승인 병합 경유 · 증명 — 종료 코드 제외 · G2 배너에 올린다) n건 ==` 절(병합 머리 `[M <sha12>] <제목> · ^1 · ^2 · 유입 k건` + 원문 + `↳ 유입: <sha12>(L 증명) · 파일 그대로`) · 요약 꼬리 ` · 승인 유입 n건(종료 코드 제외)`. exit = 남은 blocker.
