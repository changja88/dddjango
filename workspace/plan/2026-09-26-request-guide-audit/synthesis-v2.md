# 작업 요청 가이드 점검 — 종합 v2 (2026-09-26)

v1 → v2: 적대 리뷰 2건 반영 — 증거 검증(R-E: 결론 틀 유지 · 수치 «근사» 강등 · 틀린 주장 4) · 전략(R-S: 보상 지시 · 출처 규칙 · 캠페인 판형 모순 · 순서 뒤집기). v1 = `synthesis-v1.md`(이력).
틀(사용자 09-26 지적): 런타임이 가이드를 읽는 게 아니라, **가이드대로 쓴 요청은 잘 동작해야 하고(A축), 가이드를 벗어난 지시는 런타임이 걸러야 한다(B축)**. 실제 작성자가 발주자 세션이라 운영 축(C축)이 따로 있다.

## 0. 판정

- 두 가이드의 원칙(결과·규칙·보존은 사용자, 설계·배치·모드·검증은 플러그인)은 옳다. 원칙을 어긴 발주가 준수율을 깎았고, 사용자 09-26 원문도 같은 원칙이다(«디자인은 니가 어디쪽을 그리라고만 하면 알아서 자율적으로 파악할거니깐. 너는 dddjango-web이 작업을 끝내면 … 최종 확인만해» — lane-6-3-3 `GATE-web-633-2.md:140`).
- 그러나 **지금은 «최대로 끌어내는 가이드»가 아니다**:
  - A축 — 가이드대로 써도 안 되거나 약속과 다른 곳이 있다(호출명 · §6 품질 개선 · web 채널 · 철거 기능 문구).
  - B축 — 가이드 밖 지시(빚 ⓑ 선결 · 대리 이탈 · 설계 지시)를 런타임이 그대로 받는다.
  - C축 — 가이드는 금지형·출처 규칙이 없어, 정독 직후에만 효과가 나고(P2 가이드 인용 ≈93%) 판형 복사 시기(P3)에 사라졌다(≈9% — R-E 재계수 50/54 → 3/34).
- 캠페인 결정의 전제가 현장에서 성립하지 않는다: plan-v2 §9(:98) «이후 발주가 가이드를 지키고 G0 빚을 ‹지금 정리›로 답하면 순서 무관» — 가이드는 ⓐ 로 답하라는 말이 없고, P3 빚 있는 레인 22 전부 ⓑ(R-E 확인). 단 빚 상환은 전용 리팩터 발주(09-09 adapter-skeleton 연작 ≈10)로 일부 돌려졌다 — «ⓐ 가 막혔다»는 과장이고 «슬라이스 0 ⓐ 가 사라졌다»가 정확하다.

## 3. C축 — 운영(발주자 세션)

- **발주 지시 인벤토리(R-S)** — 반복 지시를 셋으로 가른다:
  - 잡음(즉시 금지): 선례 «이 꼴을 따르라» · 구현 수단(실행 입구·테스트 방식·재시도·라이브러리) · 시안 전사·요약 · 발주자 이탈 처분 · 규범 무력화 · 파일 단위 허용 목록 · 슬라이스 수·lens·모델 지정.
  - 보상(런타임 수리 뒤 금지 — 지금 금지하면 준수율↓): 수정 모드에서도 빚 스캔 요구(수정 모드 레인 30 중 28 이 이것으로 스캔) · «새 폴더로» · registry_gate 절차 · 머지 1회 · BC 단위 경계.
  - 대리 답(출처 규칙): 빚 ⓑ · BC 배치 · 모드 · 이탈 — 사용자 원문이 있으면 전달, 없으면 비워 둔다.
- **출처 규칙을 가이드의 조직 원리로** — «이미 정한 것은 사용자 원문(시각·출처)과 함께. 사용자가 정하지 않은 것은 비워 두세요 — 플러그인이 묻습니다.» 범주 금지는 사용자가 직접 정한 설계(BC·스택)까지 막아 commands:78 과 어긋난다.
- **병렬 안전** — 파일 목록 금지 · BC 단위 제외는 «범위»로 허용 · 동시 진행 브랜치 이름 제공 · 같은 파일이면 STOP(재작성본의 꼴).
- **감쇠 대책** — 지렛대는 문구 강도가 아니라 복사 원본이다. 09-26 재작성 4건(8-B-8 · 8-B-9 · web 5-1-2 · 8b3)을 정본 판형으로 두고, 가이드에 «발주서를 첨부하는 요청» 예시 하나. 가장 가까운 개입 지점 = 대상 프로젝트 CLAUDE.md · 발주자 메모리(릴리즈 불요).
- **발주 규모** — 8-B-5 = 기존 BC 넷. 빚 스캔이 BC별이라 규모가 ⓑ 압력·STOP 표면을 키운다 → §1 «따로 확인할 결과가 여럿이면 나눠 요청»(대가: 선후 의존·레인 수).
- **효과 측정** — 교정 후 발주 ≈10건(P4)을 같은 분류기로: 출처 없는 지시 비율 · ⓑ 결정 주체 · 발주 기인 STOP 비율. 분류기·시드·표를 남긴다(v1 수치 일부 재현 불가 — 아래 §6).
