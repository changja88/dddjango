# 설계 — 리팩토링 실행 수리(dddjango 2.46.0 · dddjango-web 2.9.2)

상태: 설계 검토 셋(셋째 확인 차단 0) · 계획 검토 닫힘 · 구현 뒤 바뀐 것은 `plan-2.46.0.md` «독립 검토 반영» 이 정본. 바탕 배포판 2.45.1 `9c98c18e` · web 2.9.1.

## 2. 사용자 결정

1. 늦게 찾은 흠 = 보탬 문(누가 찾았든 직접 묻는다 · 대리 답 없음). 앞 판의 «덧감사 안 함» 을 거둔다.
2. 창 판정 = 장치가 창마다 슬라이스 · 까닭을 안다. 이미 도는 실행은 지금 꼴 그대로.
3. framework 모으기 = 새 모듈만 좁게(있는 공용 모듈 편집은 이 갈래 밖).

## 3. 정한 것(운영자 처리 — 질문 생략 · 설계 처리 · 이의 시 뒤집음)

- **흠 가름**: `편집고침` = 이 실행이 내용을 고친 줄(옮김 · 이름 · import 경로 치환만 한 줄은 빼고)의 흠과 이 실행 편집 때문에 틀리게 된 줄의 흠 — 묻지 않고 고친다. 보탬 문 = 그 밖 앵커 판부터 있던 흠. 이미 처분한 흠 · 검사기가 찾은 늦은 빚은 대상이 아니다.
- **보탬 답**: 요청문 · 발주서에 미리 적은 일괄 처분은 답이 아니다. 그 흠에 닿지 않는 일은 잇고 G2 승인 전에 답을 받는다. 답을 `바꿈` 하면 이미 든 몫을 걷고 고친 편집은 `철회` 창이 되돌린다.
- **감사 시점**: 변경 창의 감사 키는 다음 변경 창을 열기 전에 판정받는다(0T · 0C · 0F · 까닭 창은 막지 않음).
- **변경 슬라이스 한 창**: 변경 창은 그 슬라이스 V 를 모두 집행해야 닫힌다. 나누려면 명세에서 나눈다.
- **앞 결정 옮김**: 배너 없이 다시 확정하는 길은 둘 — `G1 답 반영`(결정 절 뒤 · 확정 줄 전) · `재상정 반영`(뺀 항목을 걷는 반영). V 는 줄이기만. 확정 뒤 설계 반송은 G1′ 배너.
- **확정 차분**: 두 확정을 반영판 기준으로 견줘 더함 · 바뀜 · 빠짐을 슬라이스별로 싣는다. `재승인반영` 창은 그 차분 몫만 받는다.
- **설명 글 · 주석만 바꾼 시험 편집**은 어느 창이든 감사로 받는 지금 관례를 글에 적는다(범위는 ⓐ · 보탬 · 감사 반영이 정함).
- **엄격 실행** = 이 실행 첫 후보에 `side_rows_digest` 가 있는 실행(2.46.0 도구가 쓴 후보). 옛 꼴 실행의 창 판정은 2.45.1 그대로. F4-204 원점은 모든 실행에 선다.
- web 은 F4-212 짝(행 읽기)만. web 보탬 문 · 창 결속은 작업 리스트 후보.

## 4. 약속(도구 사이)

| 자리 | 꼴 |
|---|---|
| 확정 줄 | `G1 변경판 확정 <시각> · digest <12> · 후보 <12> · 명세 sha <12>` |
| 슬라이스 값 | `0T` · `0C` · `0F`(하위 이름 `0T-a` 꼴) · `S<n>` — 갈래 안은 계획 표 줄 차례 |
| 까닭 | `편집고침` · `검사반영` · `잔존반송` · `철회` · `끝맞춤` · `정렬맞춤` · `재승인반영` · `보탬` — `끝맞춤` · `정렬맞춤` 빼고 `--ref` 필수 · 그 두 까닭은 계획에 0C 행이 없어도 `--slice 0C` |
| 허용 표 | `behavior_guard.allow_table(snap, slice=, plan_row=, diff=)` 네 입력만 — `refactor_audit` 의 닫힌 창 되살림도 같은 함수 |
| 계획 행 | `## 슬라이스 계획` 절에서 머리 첫 칸이 `슬라이스` 인 표의 행 · 산출 파일 = 입장 결정이 `update` · `add` · `remove` · 재조직 `retain` 인 행의 파일만 |
| 보탬 항목 | `B<n>` · 자리 = 계획 표에서 목적 칸이 `보탬` 으로 시작하고 그 번호를 품은 모든 행 |

## 6. 한계

- 확정 줄은 자기 신고다(`--gate` 기록 결속은 다음 판 후보).
- 까닭의 진위는 장치가 구조만 보고 리뷰어가 «까닭 밖» 을 `다름` 으로 낸다.
- 마지막 슬라이스 뒤 감사가 승인 원소를 «기대 의미 그대로» 로 판정하는 드문 꼴은 그 창에서 철회가 서지 않아 멈춘다.
- 앞에 닫힌 변경 창의 편집을 뒤 창에서 되돌리는 길은 없다(지금 판부터).
- `retain` 행의 ⓐ 매임은 글 · 리뷰어만 본다.
- framework 새 모듈의 밖 import 0 은 `changes` 때만 본다(G1 · G1′).
