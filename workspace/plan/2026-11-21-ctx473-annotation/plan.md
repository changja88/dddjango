## 1. 고칠 것(`dddjango/scripts/check-context-isolation.py` · Codex byte 미러)

1. `_WindowTry.may_run_window` 걸음: 함수 스코프 바로 아래 `AnnAssign` 은 `annotation` 을 내려가지 않는다(`target` · `value` 는 그대로). 주석이 실제로 평가되는 자리는 계속 센다 — try 가 함수 밖(모듈 자리)이거나, try 몸통 안 중첩 `class` 몸통의 `AnnAssign`, 중첩 `def` 의 매개변수 · 반환 주석(3.13 이하 def 때 평가), 속성 · 첨자 대상 식(`self.x: T = v` 의 `self` · `d[key()]: T`)은 그대로. 근거: 일꾼 A 파이썬 판별 표(3.9 ~ 3.15 · 미래 import 무관 · 바이트코드 `co_names` 에 주석 이름 없음).
2. ㉠ `_runs(Name)` 은 읽기(`Load`) 마디만 «돈다» 로 센다 — 대입 · 지움 대상 이름(`read = …`)은 코드를 부르지 않는다.
3. ㉡ `_constructor_only_port_names`: 함수 몸통의 지역 이름 `AnnAssign`(대상이 단순 이름) 주석 안 이름도 «구현 증거 아님» 으로 둔다(`clock: ClockPort = self._clock` 이 ClockPort 를 크로스-BC 포트로 만들지 않게).
4. docstring ①(«이름이 글자로 없고») 에 «실행되지 않는 함수 안 지역 주석 · 대입 대상 이름은 세지 않는다» 한 구 · 꼴 ② 한계 글(1639 ~ 1641)에 «곧은 꼴 = 검증만 try · 변환은 밖» 한 구.
