`select_related`로 고쳐야 하는 전형적인 위치는 FK/OneToOne 관계를 루프나 serializer/template에서 반복 접근하는 QuerySet입니다. 예시는 이런 형태입니다:

```python
# before
orders = Order.objects.filter(status="paid")

# after
orders = Order.objects.select_related("customer", "shipping_address").filter(
    status="paid"
)
```

with self.assertNumQueries(1):
    list(Order.objects.select_related("customer"))
