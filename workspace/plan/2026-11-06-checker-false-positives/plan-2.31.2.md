## 고침

### F4-142 — 이름을 CamelCase 낱말로 나눠 판정

낱말 묶음 = `Registry` · `Dispatcher` · `Bus` · `Signal` 과 그 복수, 그리고 옛 판이 잡던 장치 이름 `Busses` · `Signaler(s)` · `Signaller(s)`.

| 이름 | 옛 판 | 새 판 |
|---|---|---|
| `BusySlots` · `BusinessHours` · `Signaling` | 걸림 | **안 걸림** |
| `EventBus` · `HandlerRegistry` · `EventDispatcher` · `DomainSignal` · `Signals` · `EventBusImpl` · `EventSignaler` · `Bus2` · `Bus` | 걸림 | 걸림 |
| `HandlerRegistries` | 안 걸림 | 걸림(복수를 함께 봄) |
| `SignalStrength` · `BusRoute` · `RegistryEntry` | 걸림 | 걸림(한계) |

### F4-145 — star import 를 그 모듈이 묶는 이름들로 편 뒤 첫 대입을 판정

묶이는 이름은 파이썬 규칙대로 잰다: `__all__` 이 있으면 그 목록, 없으면 `_` 로 시작하지 않는 모듈 수준 이름. 사슬 star 도 따라가고, 출처는 상대 · 절대 import 를 대상 저장소 안에서 찾는다.

| 무주석 재대입 | mypy strict 에서 타입을 달면 | 옛 판 #493 | 새 판 #493 |
|---|---|---|---|
| 출처의 공개 이름 · `if` 안 이름 · 사슬 star 이름 · 절대 import 출처 · `__all__` 에 든 이름 | no-redef | 걸림(모순) | **안 걸림** |
| 출처에 없는 새 이름 · `_` 시작 이름 · `__all__` 밖 이름 · 함수 지역 이름 · mypy 도 못 찾는 모듈의 star | 통과 | 걸림 | 걸림(그대로) |
| 대상 저장소 밖 모듈의 star(`from math import *` · `from django.conf.global_settings import *`) | no-redef | 걸림(모순) | 걸림(**모순 남음** · 한계) |
| star import **앞**의 대입 | 첫 대입 | 걸림 | 걸림(그대로) |
| 출처가 다시 import 한 이름 | 비엄격 no-redef · strict 통과 | 걸림 | 안 걸림(어느 모드에서도 모순 없음 · 파이썬 실행 때도 묶임) |

«star 가 있으면 그 파일을 면제» 는 고르지 않았다 — 새 이름의 #493 까지 사라진다.

구현 메모: star 가 있는 파일만 다시 파싱한 나무에 이름을 펴서 #493 걷기에 준다(다른 패스는 쓰인 그대로의 나무를 본다). 출처는 파일 하나를 검사하는 동안 한 번만 읽는다.
