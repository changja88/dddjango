## 교훈

1. 서브에이전트가 보고 `.md` 를 쓰는 것은 하네스가 막는다 — 끝 메시지로 받아 운영자가 파일로 옮긴다.
2. 대상 저장소 명령 금지는 지시문에 «읽기 전용 git 포함» 까지 적어야 지켜진다(재현 일꾼 하나가 현장 저장소에 읽기 git 을 한 번 씀).
3. 린터 명령 꼴은 설정 갈래(`fix = true` · `force-exclude` · format 이 받지 않는 플래그 · isort 표준 입력의 skip 오류)를 설계 처음부터 표로 둔다 — 이번 판은 검토가 세 바퀴에 걸쳐 좁혀 갔다.
4. ruff · isort 는 같은 모듈 from-import 를 합친다 — 감사 기준을 줄이 아니라 바인딩 집합으로.
5. 탐침이 프레임 참조를 구간 끝까지 쥐면 시험 몸의 지역 값 수명이 바뀐다(weakref 시험) — 쥔 참조는 반환 때 놓는다.
6. 계획에 적은 명령은 계획 때 한 번 돌려 본다 — 계획 검토가 없는 옵션과 매판 붉던 단계를 잡았다.
7. zsh 는 문자열 변수를 단어로 나누지 않는다 — 경로 하나씩 `git add` 는 `while IFS= read -r` 로.
