현재 /private/tmp/dddjango-codex-eval은 비어 있고, 지시된 config.toml도 없습니다. 또한 이 세션의 파일시스템이 read-only라서 main.py, requirements.txt, 테스트 파일 등을 실제로 생성할 수 없습니다.

제가 만들 설계는 다음처럼 아주 단순하게 잡겠습니다.

  • Django는 전혀 사용하지 않음
  • FastAPI 앱 하나 생성
  • GET /health가 200 OK와 JSON 응답 반환
  • 테스트는 TestClient로 먼저 작성
  • 최소 파일 구성:
  • main.py
  • requirements.txt
  • tests/test_health.py

예상 구현 형태는 이렇습니다.


# main.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/health")
def health_check():
    return {"status": "ok"}


# tests/test_health.py
from fastapi.testclient import TestClient

from main import app


def test_health_check_returns_ok():
    client = TestClient(app)

    response = client.get("/health")

    assert response.status_code == 200
    assert response.json() == {"status": "ok"}


# requirements.txt
fastapi
uvicorn
pytest
httpx
