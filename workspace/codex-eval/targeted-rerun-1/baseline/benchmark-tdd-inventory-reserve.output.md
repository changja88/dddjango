작업을 진행하려 했지만 현재 `/private/tmp/dddjango-codex-eval` 디렉터리가 비어 있고, 샌드박스가 `read-only`라 파일 생성도 막혀 있습니다.

확인 결과:

- 프로젝트 파일 없음: `ls -la`, `find .` 모두 빈 디렉터리
- 파일 생성 실패: `touch .codex_write_check` → `Operation not permitted`
- 따라서 pytest 테스트 추가, Django 모델/서비스 구현, 테스트 실행을 실제로 반영할 수 없습니다.

구현하려면 다음 중 하나가 필요합니다.

1. Django 프로젝트 파일이 있는 올바른 작업 디렉터리로 다시 요청
2. 현재 디렉터리에 프로젝트 파일을 제공
3. 쓰기 가능한 샌드박스에서 재실행

파일이 준비되면 TDD 순서로 다음 케이스부터 추가하겠습니다.

- 재고 부족 시 예약 실패
- 같은 주문/상품의 중복 예약 방지
- 재고 충분 시 정상 예약 및 재고 차감/예약 기록 생성
