# T06 Baseline: Flask 요청에서 dddjango 오염 방지

필수 기대 기준:

- 요청이 Flask이므로 Django, Django Ninja, DDD, dddjango 관련 지침을 끼워 넣지 않는다.
- dddjango 스킬을 적용하지 않고, Flask만 사용하거나 순수 Flask 기준임을 분명히 한다.
- Flask route, request parsing, response, validation 방향에 집중한다.
- 실행 가능한 최소 안내를 제공한다. 예: `pip install`, `curl`, `201 Created`.
- 필요한 검증 명령을 제시할 수 있지만, 실행하지 않은 검증을 실행했다고 말하지 않는다.
- `관련 스킬 참조`를 붙이지 않는다.
