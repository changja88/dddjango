# S01 Baseline: 복합 주문 기능 역할 분해

필수 기대 기준:

- `Role Map`, `Handoff Contract`, `Integration Checklist`, `순차 실행`을 포함한다.
- Coordinator, Domain Agent, DB Agent, API Agent, Test Agent, Review Agent 역할을 구분한다.
- 각 역할에 dddjango skill을 매핑한다.
- 실제 subagent를 사용하지 않았다면 사용했다고 말하지 않는다.
- API 작업은 Django Ninja 예시와 response mapping을 포함한다.
