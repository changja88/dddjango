# p02-domain-code-quality baseline

좋은 답변은 할인 쿠폰 정책을 도메인 코드 품질 관점에서 설명한다.

- dict 에러나 단순 bool 반환 대신 `Result` 또는 도메인 예외를 사용한다.
- 쿠폰 코드, 금액, 만료 시각처럼 검증 규칙이 있는 값은 값 객체 후보로 분리한다.
- 정상, 경계, 실패, 중복, 시간 의존 케이스를 pytest로 제시한다.
- TDD 요청이므로 RED, GREEN, REFACTOR 흐름을 지킨다.
- 타입 힌트와 명시적 실패 모델을 사용하고, 불필요한 추상화는 만들지 않는다.

에러를 `{"error": "..."}` dict로 흘리거나 테스트를 나중으로 미루면 실패로 본다.
