# 쿠폰 정책 TDD

RED 단계에서는 실패하는 pytest를 먼저 작성합니다. 정상 할인, 최소 주문 금액 경계,
만료 시간, 중복 사용, 잘못된 쿠폰 실패 케이스를 나눕니다. 시간 의존성은 time
fixture 또는 time-machine 같은 helper로 고정합니다.

GREEN 단계에서는 가장 작은 구현으로 테스트를 통과시키되, 도메인 정책은 쿠폰 정책
객체에 둡니다.

REFACTOR 단계에서는 factory로 테스트 데이터를 정리하고, 중복 fixture를 줄이며,
실패 이유를 도메인 예외 또는 명시적 Result로 정리합니다.

실제 테스트는 실행하지 않았습니다. 검증 명령은 `pytest`입니다.
