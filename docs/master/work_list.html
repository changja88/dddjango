  • F4-213folder_group.py draft --spec 은 새 도메인 서비스 파일 자리를 이름 맞추기로, 검사기 #656 · draft --run 은 반환 값 객체 자리로 내 어느 자리에 적어도 다른 쪽 의무가 걸린다그대로
